# RF 프로브 전체 기능 감사

2026-09-18 · 검토 전 A09/C03 → 검토 후 **A10/C04**

## 결론

**그대로 제작해도 모든 기능이 보장되는 상태는 아니었다.** 부품 겹침 검사에서는 통과했지만, 너트 홈·출력 턱·기둥에 실제로 얇은 벽이 남아 있었다. 이를 수정했고 저장 CAD에서 조립·개폐·케이블 삽입을 재검사했다. 뚜껑은 실제 형상을 사용한 선형 구조해석까지 실행했다.

현재 상태는 **기계 형상을 보완하고 시험할 준비를 구체화한 DRAFT**다. 무가공 실조립, 출력 뒤틀림, 반복 수명, 케이블 압착, RF 교정 정확도와 현장 보호까지 검증된 완성품은 아니다. 공급사 제출·주문·결제는 변경하지 않았다. 이전 견적을 현재 A10 구매서로 쓰면 안 된다.

얇은 벽 검사는 면적 기반 무작위 샘플의 법선 방향 통과 길이다. 작은 형상을 놓칠 수 있고 곡면/모서리에서 오해를 낳을 수도 있다. CAD 단면과 알려진 벽 치수를 함께 확인했지만 **제조사 전체 최소벽 검사나 생산 승인서를 대신하지 않는다**. 부품마다 필요한 강도가 다르므로2 mm 자체가 내구성 인증은 아니다.

원래 헤드 ERC는4개 기본 비활성 항목이 있었다. 검토 사본에서 모두 활성화하고 라이브러리까지 복사하여 다시 실행했다. 최종 `head_strict_erc.json`의 비활성 검사·위반은0이다. 원본 PCB/회로는 변경하지 않았다. 처음 라이브러리를 빠뜨린 검토 사본의 경고는 사본 구성 오류였으며 보완 후 재실행했다.

## 3. 얇아 보이던 뚜껑의 구조해석

**A09에서 이미 늘린2.4 mm 탄성부는 유지했다.** 길이63 mm, 폭18 mm인 두 연결부가 코어 높이 편차를 탄성으로 받는다. 이를 무작정 두껍게 하면 코어를 누르는 힘도 커진다.

- Gmsh4.15.2, CalculiX2.22, C3D10 직선 경계의2차 사면체. FreeCAD1.0.2 STEP 사용.
- mm/N/MPa. 탄성계수1,500 MPa는3301PA 공개 굽힘계수 참고, 포아송비0.4는 가정. 등방·선형 탄성이다.
- 양쪽 외곽 기둥 밑면의 병진을 고정하고, 두 코어 받침면에 Y방향1.8 mm 변위를 가했다. 접촉·마찰은 풀지 않았다.
- 메시61,343절점: 반력5.344 N, 적분점 최대 등가응력4.540 MPa.
- 메시169,470절점: 반력5.287 N, 적분점 최대 등가응력5.243 MPa.
- 반력 차이 약1.08%. 최대 응력 차이는 약13.4%로 **응력 수렴·허용응력 판정은 완료하지 않았다**. 재료의 공개 파단강도로 안전율을 선언하지 않는다.
- 단순 보 계산5.374 N과 반력 크기가 일치하는 것은 모델 검산의 한 근거다. 실제 닫힘 힘·수명·내구성 합격을 뜻하지 않는다.
- `.inp/.msh/.dat/.frd`, 설정, 원시 로그를 보존했다. `source_lid.step`과 현재 출력 STEP의 양방향 체적 차0을 `source_equivalence.json`으로 확인했다.

피로, 크리프(닫아 둔 동안 힘이 줄어드는 현상), 습도·온도, 출력 방향, 뒤틀림, 실제 코어 접촉과 나사 체결은 이 해석에 없다. **닫힘 힘은 계산 가능성이 확인됐고 장기 유지력은 실물 검증이 필요하다.**

초기 솔버 준비 중 물리 볼륨 선택과 곡선2차 요소의 음의 Jacobian 오류를 수정했다. 실패 로그는 A09 해석 폴더에 남아 있고, 최종 결과는 성공한 직선 경계2차 요소 모델만 사용한다.

## 4. 실제 사용 순서로 본 남은 문제

### 제작과 조립

1. **기성품 선택:** M6×110 노브·M4 손나사·사각/나일론 너트는 외형 후보가 남아 있다. 같은 나사 지름만으로 호환을 가정하지 않는다. 팔로워는 제조사 ISO7379-5-M4-20 도면과 맞췄으나 판매 단위·최종 선택을 별도 확정한다. 줄질·나사 절단을 기본 조립법으로 추가하지 않는다.
2. **출력 재료/공차:** 비전도성 무충전 나일론 후보. 일반 SLA 레진을 같은 탄성부에 자동 대입하지 않는다. 긴 가이드와254×314 바닥의 뒤틀림은 국소±0.3 mm 계산으로 보장할 수 없다. 최종 STL에 대한 업체 DFM·방향·평탄도 확인이 필요하다.
3. **실제 조임:** M6 노브에는 토크 제한이 없다. 예를 들어 토크0.1 N·m, 효율0.2, 피치1 mm라는 가정이면 축력126 N, 이상적인 세 턱 각각 약42 N이 된다. 실제 힘 예측치가 아니라 **가볍게 돌려도 외피를 누를 수 있다는 민감도 예시**다. 기존 구조만으로 과조임 안전을 선언하지 않는다.
4. **중심과 코어 접촉:** 공칭 중심 높이84 mm는 맞지만 마찰·유격·타원형 선·코어 B/E 및 평탄도는 남아 있다. 실물 Ø6/12/20 기준봉, 코어 맞댐면, 반복 개폐 위치를 먼저 확인한다. Ø26은 공칭 삽입 여유가 작아 별도 시험한다.

### VNA 교정

연결 순서는 [현재 A10 조립서](../../mechanical/assembly_A10_DRAFT/README.md)와 [G2 절차](../../docs/G2_BENCH_PROCEDURE.md)를 따른다. 보유 SOL·THRU·케이블·로드의 실제 모델과 기준면을 기록한다. 케이블2개가 필요하며 보유1개+신규1개라는 기존 계획을 유지한다.

1. 일차 신호와 귀환이 같이 코어를 통과하지 않는 PCB 경로는 유지했다. 하지만 이 PCB의 국소 전류·정합을 실제 전자기장 해석/측정한 데이터는 아직 없다.
2. T02: 코어·클램프 최종 조립 상태의 지그 반사/전달과 헤드 유무를 저장한다. 1–100 MHz S11≤−20 dB는 초기 목표이며, **정합만으로 국소 전류의 유효성까지 증명되는 것은 아니다**.
3. T03–T08: 전달,3개 이상 입력 레벨,5회 이상 재장착, 도체 위치, 왕복 상쇄, 직접 픽업을 확인한다. ±1 dB 반복성·20 dB 대조 억제 등 백서의 목표와 비교한다. 실패 대역은 제외한다.
4. 금속 나사·클램프와 코어의 거리는 CAD 값이다. 최단 클램프 금속84.65 mm라는 숫자만으로 RF 무영향을 보증하지 않는다. 금속/클램프 배치 변화, 동축 경로, 프로브 삽입 전후를 비교한다.

### 오실로스코프와 현장

- 원 MSO4054 기준의 내부50 Ω/DC결합/전압1× 설정 및 실제 정격을 확인한다. 임의 외부50 Ω를 겹쳐 연결하지 않는다.
- VNA의 SMA 기준면 교정 후 BNC 어댑터를 빼거나 스코프로 바꾸면 같은 체인 응답이 아니다. BNC 기준면/어댑터와 스코프 채널의 응답 확인 전에는 **전압·상대 비교**로 한정한다.
- 현재 분석 코드는 조건이 확인된 단일 정현파 성분 전류 RMS만 지원한다. **광대역 잡음/과도파형 전체를 교정된 전류 파형으로 복원하는 기능은 아직 없다.** 이것은 사용 목적에 대한 남은 기능이며 숨기지 않는다.
- 10 dB 감쇠기는 서지 제한기나 절연 장치가 아니다. PROT-01 선정·잔류전압·펄스 정격 검증이 끝나지 않았으므로 현장 장비에 바로 쓰는 단계가 아니다.

이 항목들은 버튼으로 통과시킬 수 있는 CAD 검사가 아니다. [측정 파일과 다음 확인 순서](NEXT_CHECKS.md)에 한 번에 모았다.
