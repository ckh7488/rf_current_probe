# A12 / C06 — 너트 조립과 제작성 재검토

2026-09-18 · DRAFT — NOT FOR FABRICATION

## 판단

기존 설계의 **너트 조립 여유 자체는 불량이 아니다.** 고정용 너트는 약간 움직여 나사 축을 맞추고, 조이면 본체의 받침면에 닿아 체결력을 전달한다. 억지로 끼우는 치수로 만들면 출력 오차 때문에 조립이 더 어려워진다.

다만 다음은 수정할 이유가 있었다.

- 프로브·케이블 가로대를 열 때 나사를 완전히 빼면 너트가 빠질 수 있었다.
- 교정 PCB의 작은 육각 너트는 공구로 반대쪽을 잡아야 했다. 포켓을 육각 너트에 꼭 맞추기만 하면 출력 오차에 대한 여유가 부족하다.
- 바닥 모듈을 떼어낼 때 밑면의 너트가 빠질 수 있었다.
- 구경 조절 축의 얇은 너트 두 개를 서로 잠그는 초도 조립은 공구 접근이 까다로웠다.

따라서 반복 개폐부에는 탈락 방지를 추가하고, 작은 교정 PCB 너트는 날개로 회전을 막는 구조로 바꿨다. 모든 체결부를 새로 설계한 것은 아니다. 코어 고정바 M3와 작은 헤드 PCB M2의 초도 조립은 기존 공구 접근을 유지한다.

## 수정과 사용 순서

| 위치 | 변경 | 초도 조립 / 반복 사용 |
|---|---|---|
| 프로브 개폐 2곳 | 기존 M4 사각 너트 + 공용 덮개 | 열린 입구로 너트를 놓고 덮개 정면을 눌러 장착. 뚜껑을 열 때 덮개는 남긴다. |
| 앞뒤 케이블 가로대 4곳 | 기존 M4 사각 너트 + 같은 덮개 | 케이블을 넣을 때 손나사와 가로대만 제거한다. |
| 교정 PCB 4곳 | M3 나일론 날개 너트 + 회전 방지 받침 + 같은 덮개 | PCB를 올리기 전에 너트를 설치한다. 이후 위쪽 나사만 조인다. |
| 바닥 모듈 6곳 | 격자 밑판 1개, 별도 M4 고정 2곳 | 처음 뒤집어 너트와 판을 설치. 모듈용 나사 6개를 풀어도 판은 남는다. |
| 케이블 구경 노브 축 2곳 | M6 얇은 너트 2개씩 → 풀림 방지 너트 1개씩 | 와셔·너트를 먼저 놓고 축을 넣는다. 10 mm 스패너로 너트를 잡고 노브를 돌린다. 자유 회전 여유는 유지한다. |

공용 덮개는 **체결 하중을 받지 않는다.** 나사를 조이는 힘은 너트 뒤의 두꺼운 본체가 받는다. 덮개는 나사를 뺐을 때 너트가 빠지는 경로만 막는다. 장착 시 정면을 눌러 넣으며, 정비 때 옆 창의 두 걸림턱을 누르고 뺀다. 좁은 통로 안으로 손가락을 넣은 채 밀어 넣는 방식이 아니다.

덮개가 너트를 정밀하게 자동 정렬하는 것은 아니다. 포켓 안의 작은 여유로 나사를 시작할 위치를 맞추며, 첫 나사산은 손으로 가볍게 돌려 물린 뒤 조인다. 걸리는데 강제로 돌려 넣는 조립을 전제로 하지 않는다. 조임 전 약간의 너트 움직임과 조인 후 조립체가 흔들리는 것은 구분한다.

**드문 덮개 정비에는 조립 순서가 있다.** 교정 PCB 받침의 덮개는 프로브 헤드를 바닥에 올리기 전에 설치·정비하고, 앞 케이블 클램프의 덮개를 정비할 때는 해당 클램프 모듈을 바닥에서 먼저 뺀다. 평소 케이블을 넣거나 뚜껑을 여는 작업에는 이 분해가 필요 없다.

M6 구동 너트 홈의 **공칭 1 mm 방향 전환 여유**는 위의 고정용 너트와 다르다. 반대 방향으로 돌릴 때 먼저 소진되는 기구 여유이며, 축 고정 너트를 꽉 조여 없애는 것이 아니다. 마지막 위치는 조이는 방향으로 맞춘다.

## 검증 범위

실행 결과는 각 원본 CAD의 해시와 함께 저장한다. 완성 위치의 겹침, 나사·너트·덮개 삽입/분리, 열린 상태, 기준면과 나사 끝, 공구 게이지, 출력용 솔리드/STL, 치수 민감도를 분리한다. 변형된 덮개 형상의 경로 검사는 걸림부가 휘어질 공간의 대용 검사이며, 접촉력·삽입력 해석은 아니다. 표본 벽 두께 검사는 전체 최소 벽 두께의 증명이 아니다.

새 나일론 걸림팔은 설치 후 공칭 변형이 0인 상태다. 손가락 접근은 형상 게이지로 검사하지만 실제 손조작 시험은 아니다. 날개 너트는 제조사 치수에 근거한 보수적인 외형 모델이며, 실제 둥근 면과 기울어진 날개 표면을 모두 재현한 정밀 모델이 아니다.

새 바닥 판 고정 금속은 코어 창을 관통하는 도전 루프를 만들지 않도록 배치했다. 단순 이격거리로 RF 무영향을 선언하지 않는다. 최종 실물 구성으로 교정·삽입 영향·개폐 반복성을 확인해야 한다.

## 실제 제작에서 남는 확인

1. 정확한 기성 나사·너트 치수와 선정 후보의 호환성 확인.
2. 3301PA 출력물의 휨·수축·표면, 너트 삽입, 덮개 걸림/해제, 분말 제거 확인. 다른 수지/FDM으로 자동 대체하지 않음.
3. 장기간 걸림 유지, 뚜껑 탄성부와 코어 맞댐, 케이블 압착 및 구동 축 풀림 확인.
4. 최종 조립 후 주파수 응답·교정·반복성과 입력 보호 시험.

이전 업체 제출 파일·장바구니·인보이스는 변경하지 않았다. 새 CAD가 이전 주문에 자동 반영되지 않는다.
