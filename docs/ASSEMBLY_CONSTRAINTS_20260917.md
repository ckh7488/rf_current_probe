# 현행 조립 가능 범위

2026-09-21 갱신 · [현재 상태](CURRENT_READINESS.md)

- 사용자가 수행할 작업: 권선 감기, 절연테이프/에나멜 끝선 처리, 납땜, 기성 나사·너트를 손/드라이버/규격 스패너로 조립.
- 동판·동띠 절단, 드릴·줄질, 작은 실리콘패드 재단/접착, 압입 인서트, 별도 스프링, 너트 분실방지 덮개/밑판은 현행 구성에 없다.
- 반복 체결은 관통 홀과 기성 너트. 프린트 자체 나사산을 반복 잠금부로 사용하지 않는다.
- M4×70/M6×120은 기성 길이 그대로 사용한다. 임의절단이 필요없는 품번을 기준으로 하되 소량구매는 아직 확인 중이다.
- C04 팔로워는 선정된 NBK SBSMS-M4-5-20 어깨나사. 일반 M4 나사로 치환하지 않는다.
- 무가공 조립을 목표로 하지만 모든 출력/핀·홀 공차와 첫실물 맞춤이 통과한 것은 아니다. 걸린 부품을 나사힘으로 당기거나 임의 드릴가공하지 않는다.
- 10 mm 스패너는 검토한 머리폭18/두께4 mm 외형 이내 기준. 임의 크기 몽키스패너 전부가 맞는다는 뜻이 아니다.

현재 출력 15종·20개, 공통축 높이88 mm. 교정PCB 장착 인터페이스 변경은 BaseCenter에 영향을 주므로 교정 설계와 분리해 최종확정하지 않는다.

과거 실리콘 패드 치수표는 [보존본](../reviews/full_audit_20260921/ASSEMBLY_CONSTRAINTS_20260917_before.md)이며 현재 제작 지시가 아니다.
