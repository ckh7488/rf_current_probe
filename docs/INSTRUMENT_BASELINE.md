# 보유 장비의 문서 기준과 첫 확인

아래는 제조사 매뉴얼과 사용자 잠정 진술의 구분이다. 실물 성능을 측정한 값이 아니다. 현재 벤치 순서는 [절차서](G2_BENCH_PROCEDURE.md)를 따른다.

## 오실로스코프 잠정 등록 — 2026-09-15

- 사용자 원문: “Mso4054 tektronix꺼일걸”. **OBSERVED — 사용자 잠정 진술**이며 실물 식별이 완료된 상태는 아니다.
- 잠정 모델: **Tektronix MSO4054**. 실제 명판이 다른 경우 해당 모델 자료로 다시 확인한다. MSO4054B·MDO4054·MSO54 자료를 혼용하지 않는다.
- 제조사 근거: [MSO4000/DPO4000 Specifications and Performance Verification, 077-0247-01 Rev.A](https://download.tek.com/manual/077024701Rev_A_web.pdf), 본문 1–1~1–3 및 1–7쪽. 조회일 2026-09-15. 아래 수치는 문서 사양이며 보유 장비의 실측값이 아니다.

| 항목 | 공식 문서에서 확인한 MSO4054 사양 / 조건 |
|---|---|
| 아날로그 채널 | 4채널 |
| 입력 저항 | 1 MΩ 또는 50 Ω 선택; DC 결합 시 50 Ω ±1% |
| 50 Ω 대역폭 | 5 mV/div~1 V/div: DC~500 MHz; 2~4.98 mV/div: DC~350 MHz; 1~1.99 mV/div: DC~200 MHz |
| 대역폭 조건 | FULL 설정, 주변 온도 ≤30 °C; 초과 시 상한 주파수 1%/°C 감소. 사양 적용 전 20분 예열 및 SPC 조건 확인 |
| 50 Ω 최대 입력 | 5 V RMS, 피크 ≤±20 V 및 DF≤6.25% 조건. 이 한계를 운용 목표나 프로브의 서지 정격으로 사용하지 않음 |
| 최대 샘플링 / 레코드 | 2.5 GS/s / 10 M points. 실제 설정·모드·파일 저장 절차는 장비에서 확인 필요 |

설계 적용: 실물 모델과 입력 상태가 확인되면 `RF 헤드 SMA → 50 Ω SMA–BNC 동축(R06) → BNC 아날로그 입력(CH1~CH4, 내부 50 Ω)`을 기본으로 한다. 새 현장·새 케이블의 첫 측정·착탈·전원 투입 때는 헤드 SMA 뒤에 10 dB 감쇠기(R05)를 넣어 최대값을 먼저 확인한다(강력 권고, DEC-055). 스코프 체인 응답은 LibreVNA CW 출력으로 확인한다. 내부 50 Ω를 사용할 때 외부 50 Ω feed-through를 추가로 병렬 연결하지 않는다. 스코프의 DC coupling 설정은 프로브에 DC 측정 기능을 추가하지 않는다.

문서 사양으로는 우선 목표인 1~100 MHz의 시간 관측에 필요한 대역을 검토할 수 있다. 실제 감도·잡음·주파수 응답·체인 보호 검증은 남아 있다. TBD-01은 **일부 정보 확보 / 미해결**로 유지한다.
