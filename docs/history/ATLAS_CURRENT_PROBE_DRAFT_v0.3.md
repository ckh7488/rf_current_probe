## 1. 왜 만드는가

출발점은 크레인에 사용하는 Ethernet/24 V 하네스의 간헐 장애다. 실험실에서도 오류가 발생하고, 현장에서는 더 자주 나타나며, 회전 상태와 통신 이상이 연관되는 사례가 보고됐다. CRC/Symbol error, Link down, UDP 누락·버스트 등이 관찰됐지만 원인은 아직 확정되지 않았다.

이 프로젝트에서 확인하려는 질문은 **“오류가 발생하는 순간, 케이블의 특정 경로에 고주파 전류 변화가 함께 나타나는가?”**이다. 프로브 출력 파형과 통신 오류·회전 상태·전원 상태의 기록을 비교해 원인 후보를 좁힌다.

별도로 만드는 Ethernet VNA 지그는 수동 신호 경로의 전달·반사를 조사한다. 이번 프로브는 실제 케이블을 감싸고 그 안을 통과하는 전류를 관측한다. 두 도구는 서로 다른 관측값을 제공한다.

| 도구 | 알아보려는 것 |
|---|---|
| Ethernet VNA 지그 | 신호가 수동 경로를 얼마나 잘 통과하고 어디서 반사되는가 |
| RF 전류 프로브 | 선택한 케이블 묶음에 어떤 고주파 합전류가 흐르는가 |
| 오실로스코프와 시스템 로그 | 전류 변화와 오류가 언제 발생하고 반복해서 겹치는가 |

RF 전류와 오류가 동시에 나타나면 연관성을 조사할 근거가 생긴다. 그 사실만으로 노이즈의 발생원이나 포트 손상 원인이 확정되는 것은 아니다.

## 2. 무엇을 만드는가

케이블 중간에 열어서 장착하는 **수동 집게형 RF 전류 프로브**를 만든다. 케이블의 커넥터를 분리하거나 Ethernet 신호 핀에 직접 연결할 필요가 없도록 설계했다. 센서 자체에는 전원을 공급하지 않는다.

![집게 A0.3의 닫힘과 열림 CAD 미리보기](E:/Current_Probe/mechanical/clamp_A03_DRAFT/assembly_preview.png)

*그림 1. 저장된 A0.3 CAD로 만든 이미지다. 실물 사진은 아니다. 회색은 코어, 청록색은 하우징, 금색은 권선·SMA, 녹색은 작은 헤드 PCB다. 오른쪽은 잠금 나사를 제거하고 90° 연 모습이다.*

측정 신호는 다음 순서로 전달된다.

```text
케이블에 흐르는 RF 합전류
        ↓ 자기 결합
분할 페라이트 코어 + 권선
        ↓ 전기 신호
작은 헤드 PCB → SMA·동축 → 정의된 감쇠·보호 체인 → 50 Ω 수신기
```

개발물은 네 부분으로 구성된다.

| 구성 | 하는 일 |
|---|---|
| 프로브 헤드 | 코어·권선으로 전류를 감지하고 PCB·SMA로 출력을 연결한다 |
| 집게 하우징 | 코어를 열고 닫으며 접합면과 도체 위치를 재현한다 |
| 교정지그 | 실험실에서 전류 경로를 통제하고 프로브의 응답을 확인한다 |
| 분석 도구·기록 | 원시 데이터와 측정 조건을 보존하고, 유효한 조건에서 전류로 환산한다 |

처음 확보하려는 범위는 **1~100 MHz에서 재현성 있는 측정**이다. 전체 개발 목표는 **100 kHz~300 MHz**, 500 MHz는 특성 확인·확장 목표다. 100 MHz는 최종 상한이 아니며, 현재 어느 대역도 실측 성능으로 보장하지 않는다.

Rev.A에는 ADC, MCU, 디스플레이, GUI, RJ45/PHY 회로를 넣지 않는다. 보유 LibreVNA로 실험실 특성을 확인하고, 오실로스코프로 시간 변화를 관측하는 구성을 우선한다.

## 3. 실제로 어떤 전류가 보이는가

### 집게 안을 지나는 전류의 합을 본다

프로브는 구멍을 통과하는 전류를 방향까지 포함해 더한 값에 반응한다. 이를 **합전류 `IΣ`**라고 부른다. 각 도체가 한 번 통과하면 다음과 같다.

`IΣ(t) = i₁(t) + i₂(t) + …`

예를 들어 같은 순간에 한 선으로 10 mA가 나가고 다른 선으로 10 mA가 돌아오면 두 전류는 상쇄된다. 두 선을 함께 감싼 프로브의 합전류는 이상적으로 0이다. 이런 정상 왕복 성분이 상쇄되고 남는 RF 전류를 관측하면, 의도한 왕복 경로 밖으로 흐르는 전류를 조사할 수 있다.

**무엇을 함께 감싸는지가 측정값의 의미를 결정한다.** Ethernet 도체군에 +10 mA, 함께 통과하는 쉴드나 전원 귀환에 −10 mA가 흐르면 전체 묶음은 거의 0으로 보일 수 있다. 따라서 전체 하네스 값이 작다는 이유만으로 내부의 공통모드 스트레스까지 작다고 결론 내리지 않는다. 이 예는 같은 순간의 부호 있는 전류이며, 따로 측정한 스펙트럼 크기를 단순히 빼는 방법을 뜻하지 않는다.

현장에서는 우선 기존 케이블 구조를 유지한 전체 묶음을 관측한다. 접근 가능한 지점에서만 Ethernet 도체군, 전원 도체군, 쉴드 접속 경로를 구분한다. 측정을 위해 보호접지나 쉴드를 임의로 끊지 않는다.

### 출력 전압을 전류로 바꾸려면 감도를 알아야 한다

이 센서는 변류기, 즉 CT(Current Transformer) 원리를 사용한다. 케이블의 변화하는 전류가 코어에 자속을 만들고, 코어에 감은 권선과 부하에서 출력 신호가 생긴다. 일정한 DC 전류를 측정하는 센서는 아니다. 다만 상쇄되지 않은 DC는 코어의 상태와 RF 감도에 영향을 줄 수 있다.

출력 전압과 입력 전류의 관계를 **전달 임피던스 `ZT`**로 정의한다.

`ZT(f) = Vout(f) / IΣ(f)`

단위는 Ω이며 V/A와 같다. 여기서 `Vout`은 정의된 **50 Ω 부하에 걸리는 전압**이다. 주파수에 따라 감도가 달라지므로 최종적으로는 한 숫자가 아니라 주파수별 교정표가 필요하다.

계산 예로, 어떤 주파수에서 검증된 `ZT`가 5 Ω이고 같은 출력 조건에서 5 mV RMS를 읽었다면 전류는 1 mA RMS다. 이는 식을 설명하는 예시이며 현재 프로브의 실측 감도나 최소 검출 전류가 아니다.

5턴·50 Ω 부하의 이상적인 중간 대역 근사는 `ZT ≈ 50/5 = 10 Ω`이다. 실제 값은 코어, 접합면, 권선, 배선, 출력 체인의 영향을 받으므로 측정해야 한다. 특히 넓은 대역의 펄스 피크 전압을 이 10 Ω으로 나눠 실제 피크 전류라고 표시할 수는 없다.

## 4. 현재 설계는 어떻게 정했는가

아래는 **첫 시제품을 만들기 위해 선택한 구성**이다. 성능 시험을 거쳐 고정된 최종 사양은 아니다.

| 항목 | 현재 설계와 선택 이유 | 남은 확인 |
|---|---|---|
| 장착 방식 | 집게형. 커넥터 분리 없이 케이블 중간에 장착 | 실제 다발 굵기와 주변 개폐 공간 |
| 코어 | Fair-Rite **2644181281**, 44 재료, 물리적 반쪽 2개. 내부 공간과 짧은 축방향 길이를 우선 | 판매 단위가 반쪽인지 한 쌍인지, 실물 치수·접합 상태 |
| 권선 | 고정 반쪽에 **5턴**, 도체 지름 약 0.3 mm 에나멜선. 가동부로 전선을 넘기지 않음 | 피복 외경·절연·리드 길이·위치 민감도 |
| 권선 비교 | 같은 코어로 **5 → 3 → 7턴** 순서 비교 예정 | 실제 감도·저주파 응답·고주파 응답 |
| 유효 구경 | 권선·절연·기구를 포함해 **30 mm 목표** | 출력물과 실제 권선을 포함한 통과 공간 |
| 헤드 PCB | **A0.2**, 20×16 mm, 2층, 공칭 1.6 mm. 권선 두 끝을 SMA에 짧게 연결 | 제작 조건·납땜·실제 SMA 체결 |
| 헤드 SMA | **GCT RFPC-SMA28-F**, 수직 관통형 | 실물 체결 공간과 케이블 하중 |
| 종단 | 수신기 쪽 단일 **50 Ω**. 헤드에는 병렬 50 Ω 저항 없음 | 실제 수신기 설정과 부하 일치 |
| 하우징 | **A0.3**, SLS 나일론 출력안, 나일론 힌지·나사 잠금, 90° 스토퍼 | 출력 공차·잠금 힘·강도·반복성 |
| 차폐 | 첫 저레벨 VNA 벤치는 차폐 없이 시작 | 직접 픽업을 측정한 뒤 추가 필요성 판단 |
| 수신기 | 실험실 교정은 LibreVNA, 시간 관측은 잠정 **Tektronix MSO4054** | 실제 모델·버전·입력 상태와 보호 체인 |

턴 수를 늘리면 저주파 응답에 유리할 수 있지만, 같은 50 Ω 부하에서 이상적인 중간 대역 감도는 낮아지고 권선의 기생 성분도 바뀐다. 턴 수를 줄이면 감도가 커지는 대신 측정 대상에 주는 부하도 커질 수 있다. 그래서 5턴을 출발점으로 두고 실측으로 비교한다.

기구에서는 코어 두 반쪽의 맞댐 상태가 중요하다. 접합면 사이에 패드·테이프·접착제를 넣지 않고, 패드는 코어의 뒤쪽과 바깥쪽을 지지하는 데 사용한다. 잠금은 현재 **M3×16 나사와 작은 드라이버**를 사용하는 방식이다.

### 설계하면서 바뀐 부분

| 처음 검토했던 것 / 발견한 문제 | 현재 반영한 내용 |
|---|---|
| 닫힌 코어는 장착 시 커넥터 통과를 고려해야 함 | 사용자 선택에 따라 집게형으로 변경 |

## 5. PCB 교정지그와 캘리브레이션

프로브 출력 전압을 전류로 바꾸려면 **코어 안의 전류와 출력의 관계**를 알아야 한다. 교정지그는 전류 경로를 통제하고 그 관계를 조사하는 실험 장치다. VNA의 케이블 교정과 프로브의 전류 감도 교정은 별도 단계다.

### 동판에서 PCB로 바꾸는 부분

기존 F-A는 동판·동띠 절단과 홀 가공이 필요했다. 새 PCB A0.1 초안은 **Frame 1장 + 같은 EndPanel 2장**으로 이 부분을 대체한다. 납땜·나사 조립을 중심으로 하되, 권선 감기·피복 제거·간단한 패드 재단은 남는다. 사용자에게 금속 절단·드릴·줄질을 요구하지 않는 방향이다. 실제 출력 공차와 끼움은 아직 확인 전이다.

![새 PCB 교정지그 조립 CAD](E:/Current_Probe/hardware/calibration_fixture_PCB_A01/assembly/assembly_preview.png)

*새 PCB 지그와 집게 A0.3의 저장 CAD 이미지다. 금색 중앙 신호 경로만 코어 안을 지나고, 양옆 귀환은 밖으로 돌아간다. 실물 사진이나 RF 검증 결과가 아니다.*

| 부품 | 현재 설계값 | 연결 역할 |
|---|---|---|
| Frame × 1 | 118×65×1.0 mm, 중앙 다리 폭 8 mm | 양면 SIG 동박을 중앙에, 귀환 레일을 양옆에 배치 |
| EndPanel × 2 | 128×24×1.0 mm, SMA 홀과 레일 슬롯 | 양옆 귀환을 서로 연결하고 SMA 외피로 복귀 |
| 짧은 연결선 | 실제 접점에 맞춰 조립·기록 | SMA 중심을 Frame SIG에 직접 연결. EndPanel GND와 분리 |

![원본 PCB 형상에서 신호 경로 강조](E:/Current_Probe/docs/atlas/review/cad/path-signal.png)

**중앙 다리의 앞·뒤 동박은 모두 SIG다.** 신호 바로 아래에 GND를 깔아 함께 코어를 통과시키면 왕복 전류가 상쇄될 수 있다. 귀환은 코어 밖의 양옆 레일을 사용한다. 그림은 저장 CAD의 원래 형상이다. Atlas에서는 집게 열기·닫기, PCB만 보기, 경로 강조와 회전·확대를 직접 할 수 있다. 동박 색은 경로 구분용이며 제작 승인이나 RF 검증을 뜻하지 않는다.

### 네 단계로 연결하기

아래는 같은 원본 조립 CAD의 단계별 화면이다. 케이블·상대 커넥터·부하·교정 표준의 외형은 연결 위치 설명용이다. 실제 보유품의 모델·성별·길이는 별도로 확인한다. [3단계 원본 CAD 바로 보기](https://ckh7488.github.io/showcase/reports/rf-current-probe/?step=3#calibration).

P1은 신호를 보내는 포트, P2는 신호를 받는 50 Ω 포트다. 아래 연결을 바꾸기 전에는 항상 **RF OFF**, 재배선 후에는 일차와 프로브 출력의 종단을 확인한다.

| 단계 | P1 | P2 | 외장 50 Ω 부하 | 확인하는 것 |
|---|---|---|---|---|
| 0. VNA 교정 | 테스트 케이블 끝에서 O/S/L/T | 테스트 케이블 끝에서 O/S/L/T | 실제 교정 표준 Load를 순서대로 사용 | VNA·케이블의 측정 오차와 기준면 |
| 1. 지그만 | 지그 IN | 지그 OUT | 사용 안 함. P2가 일차 종단 | 지그 반사·손실·위상 |
| 2. 헤드 장착 | 지그 IN 그대로 | 지그 OUT 그대로 | 프로브 SMA 출력 | 헤드 장착이 일차 경로에 주는 영향 |
| 3. 프로브 전달 | 지그 IN 그대로 | **프로브 SMA 출력으로 이동** | **지그 OUT으로 이동** | 입력에 대한 프로브 출력의 상대 S21 |

0단계에서는 모델·성별이 맞는 Open/Short/Load를 각 케이블 끝에 순서대로 연결하고, 두 케이블 끝 사이의 Thru도 측정한다. 지원되는 전체 2포트 교정을 적용하고 검증용 부하·Thru를 재접속한다. 알 수 없는 어댑터를 길이 0의 Thru로 가정하지 않는다.

![VNA 기준면 교정](E:/Current_Probe/docs/atlas/review/cad/step-0.png)

1단계는 헤드를 분리하고 지그만 측정한다. `fixture_empty.s2p`를 저장한다. 2단계는 헤드를 장착하고 출력을 외장 50 Ω로 종단해 `fixture_probe_loaded.s2p`를 저장한다. 이때 P2는 계속 지그 OUT에 있다. 이 두 파일의 S21은 지그 전달 특성이다.

![지그 단독 측정](E:/Current_Probe/docs/atlas/review/cad/step-1.png)

![헤드 장착 영향 측정](E:/Current_Probe/docs/atlas/review/cad/step-2.png)

가장 중요한 전환은 **2 → 3**이다. RF를 끈 뒤 P2 케이블을 프로브로 옮기고, 프로브에 있던 외장 부하를 지그 OUT으로 옮긴다. 같은 부하 한 개를 재사용할 수 있다. 일차 회로와 권선 출력은 별도 경로이므로 각각 한 번씩 50 Ω로 종단한다. 한 출력에 50 Ω 두 개를 병렬로 붙이는 이중 종단이 아니다.

![프로브 전달 측정](E:/Current_Probe/docs/atlas/review/cad/step-3.png)

3단계에서 `probe_transfer_01.s2p`와 같은 이름의 JSON을 저장한다. 헤드·지그·케이블·부하 ID, 교정 ID와 기준면, 턴 수·극성, 도체 위치, 레벨·주파수·IF BW·평균·온도·시각을 기록한다. 전류 모델 확인 전에는 `relative` 모드로 두고 ZT/A 값을 만들지 않는다.

시작 설정안은 **1~100 MHz / 401점 linear / −20 dBm / IF BW 1 kHz**이며, 평균은 실제 설정값을 기록한다. 장비 지원값·정격·실제 선형 범위를 우선한다. 후속으로 레벨 변경, 최소 5회 재장착, 도체 위치, 왕복 상쇄, 직접 픽업·잡음을 비교한다. 실패 구간도 원시 파일로 보존한다.

### 언제 출력 전압을 전류로 바꾸는가

동일한 실수 50 Ω 기준 임피던스, 충분한 정합, 코어 전류를 입력 진행파로 근사할 수 있는 조건, 정리된 케이블·기준면과 50 Ω 출력 부하에서만 `|ZT| ≈ 50×|S21|`을 적용한다. `S21`은 dB가 아닌 선형 진폭비다. 예를 들어 −20 dB는 0.1이므로 ZT는 5 Ω이고, 이 조건의 5 mV RMS 정현파는 1 mA RMS에 해당한다. 이는 **설명용 계산**이지 이 PCB 지그의 실측 감도가 아니다.

좋은 S11만으로 코어 위치 전류를 입증할 수는 없다. `1−S11` 보정도 입력 기준면과 코어 위치 사이 전류 분기·지연이 정리된 모델에서만 사용한다. 조건을 입증하지 못하면 같은 지그·연결에서의 상대 응답으로 남긴다. 누설·잡음·선형성·반복성·위치 의존성이 검토되지 않은 주파수는 정량화하지 않는다.

### 스코프로 옮길 때

RF OFF 후 재배선하고 벤치 소스는 CW/P1만 활성화한다. 기본 연결은 `헤드 → 검증된 감쇠·보호 → SMA–BNC → 스코프 내부 50 Ω`다. 실제 MSO4054 모델·입력 상태 확인 후 DC coupling / Voltage 1× / FULL / Sample 설정안을 적용한다. 내부 50 Ω와 외장 50 Ω를 병렬로 쓰지 않는다.

먼저 **V 단위 원시 파형**을 저장한다. BNC 입력 위치까지의 교정, 같은 체인, 스코프 응답·부하가 확인된 단일 주파수 기본파 RMS만 전류로 환산한다. VNA용 어댑터를 빼면 교정 조건이 달라지고, VNA 교정은 스코프 내부 응답을 자동 보정하지 않는다. 펄스 피크를 임의의 한 ZT로 나누지 않는다.

자세한 실행 기록 양식은 [벤치 체크리스트](C:/Users/artzy/Documents/ChatGPT/test_board/showcase/reports/rf-current-probe/records/bench-checklist.md), 원칙과 한계는 [기존 벤치 절차](E:/Current_Probe/docs/G2_BENCH_PROCEDURE.md)와 [전체 연결 절차](E:/Current_Probe/docs/END_TO_END_REHEARSAL.md)를 따른다. 이전 동판 지그의 기구 검사·견적을 새 PCB 지그에 전용하지 않는다.

초기 내부 목표는 재장착 5회에서 1~100 MHz 응답 변화 ±1 dB, 입력 레벨 10 dB 변화에 출력 레벨 10±1 dB 변화, 유효 신호보다 20 dB 이상 낮은 직접 픽업이다. 아직 달성한 수치는 아니다. 선형성 시험에서 정규화된 비율인 S21은 거의 일정해야 한다.

스코프 단계에서는 검증된 체인으로 원시 **전압 파형**부터 저장한다. 전류로 환산하려면 스코프 BNC 입력 위치까지의 교정과 실제 수신기 응답·부하 확인이 추가로 필요하다. 단순히 VNA에서 사용한 어댑터를 빼고 꽂았다는 이유로 기존 교정을 그대로 적용하지 않는다.

현장 적용 전에는 계측기 입력 보호, 프로브 장착에 따른 전류·링크 변화, 순 DC 전류에 따른 감도 변화를 확인한다. 감쇠기를 서지 보호기로 간주하지 않으며, 장착·배선 변경은 안전한 정지·무전원 절차로 수행한다. 현재 시제품의 대상은 검토된 저전압 하네스이며, 상용전원·VFD 출력·노출 고전압·서지 시험에는 직접 적용하지 않는다.

## 8. 무엇이 확인되면 프로젝트가 완성되는가

첫 실용 단계는 같은 조건에서 RF 변화가 반복해서 관측되는 **비교용 도구**를 확보하는 것이다. 이후 코어 위치의 전류 모델과 오차를 확인하면 **전류 추정용 도구**로 범위를 넓힌다. 독립 기준과 비교한 정확도가 있어야 검증된 정량 성능을 말할 수 있다.

최종 결과물에는 다음이 함께 있어야 한다.

- 같은 것을 다시 만들 수 있는 회로·PCB·기구 원본과 부품·조립 기록.
- 실제 개체의 헤드 ID, 권선·차폐·출력 체인 구성과 교정 데이터.
- 유효 주파수 범위, 감도, 반복성, 위치 의존성, 잡음과 삽입 영향.
- 측정·분석 절차, 원시 파일, 실패 구간과 사용 한계.
- 계측기 보호 조건과 현장 적용 전후 점검 기록.

현재 가장 먼저 해소할 불확실성은 **실제 조립한 코어·권선·지그가 재현성 있는 RF 응답을 주는가**이다. 그 결과가 다음 권선 수, 지그 개선, 차폐와 상위 대역 개발의 근거가 된다.
