# 범용 RF 전류 프로브 개발 백서
## 산업용 Ethernet 장애 진단을 출발점으로 하는 수동형 전류 프로브·교정지그

| 문서 항목 | 값 |
|---|---|
| 문서 ID | RFCP-WP-001 |
| 개정 | Rev.A / 0.4 |
| 기준일 | 2026-09-23 |
| 상태 | 설계 기준서. 회로·PCB 제작 승인 및 성능 검증 전 |
| 중심 산출물 | 수동 RF 전류 프로브 헤드, 교정지그, 특성화 데이터, 분석 도구 |
| 개발 환경 | KiCad, Python, 보유 LibreVNA, 보유 오실로스코프 |
| 비용 원칙 | 기존 계측기 제외 신규 지출 10만 원 목표, 20만 원 상한. 구매 전 실견적 검토 |

> **프로젝트의 성공은 “300 MHz라고 적힌 PCB”를 만드는 것이 아니다. 케이블에 흐르는 RF 순전류를 재현성 있게 측정하고, 그 측정이 유효한 주파수·감도·부하 조건을 설명할 수 있는 도구를 만드는 것이다.**

이 문서는 프로젝트의 중심 설계 근거이자 구현 에이전트의 작업 기준이다. 앞선 대화의 개략 설명과 충돌할 때에는 이 문서의 명시적 정의·조건·검증 절차를 우선한다. 다만 새로운 실측이나 제조사 자료로 오류가 확인되면, 오류를 유지하지 말고 결정 기록과 함께 개정한다.

현행 헤드 시제품 설계는 **Fair-Rite 2644181281 두 반쪽·초기5턴, Head A04(36×28 mm), A14/C07**이다. 사용자가 정한 구경 기준은 공칭26 mm이고 실제 큰 대상은 약20 mm 수준이다. Fixture A03/A04/A05는 보존된 평판 지그 후보지만, 2026-09-23 전체 openEMS 재검토에서100–500 MHz 제조 후보로 기각됐다. 해당 대역의 절대 교정지그는 현행 제조 원본이 없다. 실물 조립·실측 교정도 아직 없다. 5턴은 비교 시작안이며 실제 대역폭·절대 정확도·내전압·허용 전류는 확정되지 않았다.

0.4 개정: 평판 지그의 전체3D 결과와 일정 단면 경계 계산을 반영했다. A04/A05를100–500 MHz 정합 후보로 부르지 않으며 JLC 교체 파일도 만들지 않는다. 지그 원리·수식·저주파 우선 검증 절차는 유지한다. [지그 재검토](../reviews/fixture_structural_redesign_20260922/ENGINEERING.md)와 [현재 상태](CURRENT_READINESS.md)를 참조한다.

0.3 개정: 현행 원본·구경·기구·PCB·지그와 문서 상태를 맞췄다. 수식, 대역 목표, 보호 원칙 및 실측 합격 기준은 유지한다. [직전 원문](history/RF_CURRENT_PROBE_WHITEPAPER_0.2_20260922_before.md), [현재 상태](CURRENT_READINESS.md), [문서 전수 조사](../reviews/document_full_audit_20260922/README.md)를 참조한다.

0.2 개정: 사용자 선택에 따라 Rev.A의 기본 장착 방식을 **집게형(split-core)**으로 변경했다. 관련 결정은 [DEC-010](DECISIONS.md), 변경 전 0.1 원문은 [이력 보관본](history/RF_CURRENT_PROBE_WHITEPAPER_0.1.md)에 남긴다. 이력 보관본은 현재 설계 기준이 아니다.

## 0. 먼저 읽을 결론

**만들 것:** 케이블이 코어 구멍을 통과하는 수동 CT(Current Transformer)형 RF 전류 프로브. 권선과 코어를 작은 PCB에 연결하고, SMA 출력으로 기존 계측기를 사용한다.

**일차 용도:** 크레인 Ethernet/24 V 혼합 하네스에서 RF 공통모드 전류와 통신 장애의 시간적 연관성을 조사한다.

**범용성:** Ethernet에 전기적으로 접속하지 않는다. 같은 원리로 다른 통신 케이블·저전압 전원 하네스·접근 가능한 쉴드 경로의 RF 전류를 관측한다. 고전압·대전류 측정까지 자동으로 허용되는 것은 아니다.

**목표 대역:** 100 kHz~300 MHz를 개발 목표로 하고, 100 kHz~500 MHz에서 가능한 범위까지 특성화한다. 먼저 1~100 MHz의 재현성 있는 측정을 확보한다. 어느 범위도 실측 전에 보장 사양으로 표시하지 않는다.

**구현 순서:** 교정 방법 검증 → 코어·권선 소수 후보 실험 → PCB/기구 고정 → 특성화 → 안전한 현장 적용.

**이번에 하지 않을 것:** VNA 자체 제작, RJ45 종합 인증기, ADC/MCU/디스플레이 통합, 정식 EMC 인증, 고전압 안전 인증, 서지 주입기.

핵심 설계 원칙은 다음 세 가지다.

1. **어떤 전류를 더해서 측정하는지부터 정의한다.** 전체 하네스 측정과 Ethernet 도체만의 측정은 같은 값이 아니다.
2. **교정지그도 측정 대상이다.** 코어 안의 전류가 알려지지 않으면 S21 그래프가 매끄러워도 전류 교정은 성립하지 않는다.
3. **측정기가 원래 현상을 바꾸는지 확인한다.** 프로브 장착과 출력 케이블 연결이 공통모드 경로를 바꿀 수 있다.

## 1. 배경과 해결하려는 질문

### 1.1 사용자 관찰

다음은 사용자에게서 보고된 현상이며, 원인이 확정되었다는 뜻은 아니다.

| 관찰 | 현재 의미 |
|---|---|
| 실험실에서도 간헐 오류, 현장에서는 더 빈번한 오류 | 실험실/현장 조건 차이와 시스템 내부 요인을 함께 조사할 필요 |
| 몇 시간 또는 며칠 정상 동작하는 경우가 있음 | 간헐 사건 포착과 장기 로그가 중요 |
| 회전 상태와 통신 이상이 연관되는 사례 | 접촉·배선·구동 상태·EMI를 분리해 비교할 필요 |
| CRC/Symbol error, Link down, UDP 누락·버스트 관측 | 물리층 오류와 상위 계층의 버퍼링 현상을 구분할 필요 |
| 컴퓨터 Ethernet 포트가 손상된 것으로 보이는 사례 | 전기적 스트레스 조사 필요. 영구 고장 여부는 별도 교차 확인 |

본 프로젝트는 이 현상들을 **공통모드 원인으로 미리 확정하지 않는다.** 관측값을 얻어 가설의 우선순위를 바꾸는 것이 목적이다.

### 1.2 이 프로브가 답할 질문

- 장애 전후에 특정 케이블 경로의 RF 전류가 증가하는가?
- 어느 주파수 성분과 시간 패턴이 변하는가?
- 전체 하네스, Ethernet 도체군, 전원 도체군의 관측이 서로 다른가?
- 배치·회전·설비 동작 조건을 바꿨을 때 변화가 반복되는가?
- 노이즈 저감 조치 후 전류와 실제 오류율이 함께 변하는가?

### 1.3 이 프로브 하나로 답할 수 없는 질문

RF 전류가 검출되었다고 그 전류가 외부에서 들어온 것인지, 장비가 만들어 내보낸 것인지 자동으로 판별되지는 않는다. 또한 전류 크기만으로 PHY 핀 전압, 포트 손상 에너지, EMC 면역도 합격 여부를 결정하지 않는다.

RF 전류가 작게 측정되어도 전압 스트레스, 대역 밖의 사건, 상쇄된 내부 전류, 놓친 짧은 펄스가 없다고 결론 내리지 않는다.

## 2. VNA 지그와의 역할 분담

| 도구 | 주요 관측 | 이 도구가 대신하지 않는 것 |
|---|---|---|
| 별도 Ethernet VNA 지그 | 수동 경로의 차동 전달·반사·페어 간 누화 | 실제 운전 중 모든 EMI/과도현상 관측 |
| 이번 RF 전류 프로브 | 선택한 도체군의 RF 순전류 | 완전한 mixed-mode S-parameter 측정 |
| 오실로스코프와 시스템 로그 | 시간 파형, 전원/RESET, 오류·링크 이벤트 | 모든 사건의 원인 자동 판정 |

이번 프로브의 교정에서 사용하는 `S21`은 **교정 전류 → 프로브 출력**의 결합 측정이다. Ethernet 경로의 `Sdd21`과는 전혀 다른 측정 연결이다. 파일명과 플롯 제목에서도 구별한다.

차동 전달이 좋다고 공통모드 취약성이 자동으로 작다는 결론은 내리지 않는다. 에너지 잔차로 아주 작은 모드 변환을 역산하려면 손실과 측정 오차를 그보다 더 작게 알아야 한다. 따라서 이 프로젝트는 `Sdd` 잔차를 공통모드 전류 측정의 대체물로 사용하지 않는다.

**VNA 정상/전류 정상이라는 두 결과만으로 조사 종료를 선언하지 않는다.** 각각의 대역, 시간 포착 범위, 종단 조건과 센서 삽입 영향을 함께 기록한다.

## 3. 용어·물리량·상태 표기

### 3.1 전류의 정의

프로브의 일차 측정량은 코어 구멍을 통과하는 전류의 부호 있는 합이다.

$$
I_\Sigma(t)=\sum_k n_k i_k(t)
$$

`n_k`는 통과 방향을 포함한 유효 통과 횟수다. 기본 사용은 각 도체가 같은 기하학적 방향으로 한 번 통과하는 구성이다. 이때 정상적인 왕복 전류는 전류 부호가 반대이므로 상쇄된다.

페어의 공통모드 전류를 `Icm=(I+ + I−)/2`로 정의하는 문헌에서는, 그 페어를 한꺼번에 감싼 클램프의 순전류가 `2×Icm`이다. 혼동을 피하기 위해 본 프로젝트의 원시 보고 단위는 **합전류 `IΣ`**로 통일한다. 다른 정의로 변환할 때만 환산식을 적는다.

### 3.2 전달 임피던스

$$
Z_T(f)=\frac{V_{out}(f)}{I_\Sigma(f)}
$$

단위는 Ω이며 V/A와 같다. 여기서 `Vout`은 **정의된 50 Ω 부하에 실제로 걸리는 전압**이다. 무부하 전압이나 임의의 1 MΩ 연결 전압이 아니다.

$$
Z_T[\mathrm{dB\Omega}]=20\log_{10}\left(\frac{|Z_T|}{1\ \Omega}\right)
$$

계측 연결은 50 Ω 측정계로 정의한다. 이것은 프로브 자체의 출력 임피던스가 전 대역에서 정확히 50 Ω라는 주장과 다르다. [R02][R03]

### 3.3 모든 수치의 상태

| 표기 | 의미 |
|---|---|
| `OBSERVED` | 사용자 또는 실험자가 관측했다고 기록한 사실 |
| `REQUIREMENT` | 설계에서 지켜야 하는 조건 |
| `TARGET` | 달성하고 싶은 목표. 아직 보장되지 않음 |
| `CALCULATED` | 명시한 모델과 가정으로 계산한 결과 |
| `SIMULATED` | 모델·설정·원본 결과가 있는 시뮬레이션 |
| `MEASURED` | 원시 데이터와 측정 조건이 있는 실측 |
| `TBD` | 정보 부족으로 미확정 |

출처가 없는 부품 사양을 확정값으로 쓰지 않는다. 계산·시뮬레이션을 실측으로 승격하지 않는다.

### 4.2 개발 목표

| 항목 | Rev.A 목표와 판정 방식 |
|---|---|
| 일차 확보 대역 | 1~100 MHz에서 재현성 있는 비교 측정과 유효한 특성화 |
| 전체 개발 목표 | 100 kHz~300 MHz. 동일한 평탄도나 정확도가 전 대역에서 보장된다는 뜻은 아님 |
| 특성 확인 범위 | 보유 장비의 유효 범위 내 100 kHz~500 MHz |
| 500 MHz 확장 | 필요하면 별도 HF 헤드. Rev.A 출하 조건 아님 |
| 장착 방식·구경 | 커넥터 분리 없이 장착하는 집게형. 2026-09-22 사용자 범위 확정: 당장 대상은 최대 약20 mm 수준, 현행 공칭26 mm 기준으로 여유 확보. 초기30~35 mm 탐색 목표를 대체한다. 실제 출력 공차를 포함한 최대 통과 지름 보증은 별도 |
| 감도 | 중간 대역에서 수 Ω~수십 Ω 범위를 비교. 최대 감도보다 대역·재현성·삽입 영향 우선 |
| 사용 전류 | mA급 RF 전류의 비교 측정을 우선. 최소 검출 전류는 계측 체인에서 실측 |
| 저주파 추가 측정 | 100 kHz 미만은 별도 검증된 장비가 있을 때만 수행 |

LibreVNA 공식 프로젝트는 기본 주파수 범위를 100 kHz~6 GHz로 제시한다. 따라서 10 kHz부터 교정했다고 가정하지 않는다. 실제 보유 기기의 하드웨어·펌웨어·GUI 버전과 유효 사양은 착수 단계에서 기록한다. [R01]

상용 32 mm 구경 프로브에도 200 kHz~300 MHz 및 400 kHz~500 MHz의 대표 3 dB 대역 제품이 있다. 이는 설계 목표의 참고점이지, 임의의 코어와 7턴 권선으로 같은 성능을 얻는다는 근거가 아니다. [R04]

## 5. 무엇을 코어 안에 넣을 것인가

| 측정 구성 | 실제로 관측하는 것 | 해석상 주의 |
|---|---|---|
| 전체 하네스와 쉴드 | 구멍을 통과하는 모든 도체·쉴드 전류의 합 | 내부 경로끼리 반대로 흐르면 상쇄 가능 |
| Ethernet 도체군만 | 포함한 통신 도체 전체의 합전류 | 두 페어 사이에서도 일부 상쇄 가능 |
| Ethernet 한 페어의 두 선 | 해당 페어의 합전류 | 다른 페어와 분리하되 배선을 과도하게 풀지 않음 |
| +24 V와 모든 관련 0 V 귀환선 | 포함한 전원 도체군의 합전류 | 병렬 전원선·귀환선 누락 금지 |
| 접근 가능한 drain 또는 쉴드 접속선 | 그 도체를 흐르는 RF 전류 | 전체 포일/편조 쉴드 전류와 동일하다고 단정하지 않음 |

예를 들어 Ethernet 도체군에 `+10 mA`, 전원 귀환 또는 쉴드에 `−10 mA`가 흐르면 전체 측정은 거의 0이 될 수 있다. **전체 하네스 값이 작다고 Ethernet 내부 스트레스까지 작다는 뜻은 아니다.** 이는 합전류 정의에서 직접 따라온다.

전류 크기는 일반적으로 위상을 가진다. 개별 측정의 dB값이나 크기값을 산술적으로 더하거나 빼서 전체 전류를 복원하지 않는다. 서로 다른 시각에 측정한 크기 스펙트럼에는 합산에 필요한 위상·동시성 정보가 없다.

### 현장 적용 원칙

먼저 기존 케이블 외형을 유지한 전체 측정을 수행한다. 분리 측정은 접근 가능한 지점에서만 진행하며, 커넥터·쉴드·꼬임 구조를 변경했다면 별도 시험 구성으로 식별한다.

쉴드 전류를 재기 위해 정상적인 360° 접속을 긴 피그테일로 바꾸지 않는다. 분리 측정이 불가능하면 `N/A — 비침습 접근 불가`로 남긴다. 측정 편의를 위해 실제 고장 조건을 다른 회로로 바꾸는 것을 피한다.

## 6. 시스템 구조와 제작물

기본 신호 흐름:

**측정 도체군 → 페라이트 코어/2차 권선 → 헤드 PCB → SMA/동축 → 보호·감쇠 체인 → 50 Ω 수신기**

이 시스템은 PCB만으로 완성되지 않는다. 코어·권선·차폐·기구가 센서의 핵심 부품이다.

### 6.1 제작 단위

| 단위 | 역할 |
|---|---|
| Probe Head | 코어, 절연, 권선, 차폐, 작은 RF 인터페이스 PCB |
| Calibration Fixture | 알려진 전류를 코어 안에 만들기 위한 중심 도체·외부 귀환 구조·커넥터 |
| Measurement Chain | 출력 동축, 감쇠기/보호장치, 수신기 측 종단 |
| Analysis Package | S-parameter 처리, 전달 임피던스 표, 유효 대역 마스크, 보고서 |

교정지그는 작은 커넥터 PCB 여러 장과 기구물로 구성할 수 있다. “반드시 PCB 두 장으로 끝낸다”는 제약을 두지 않는다.

### 6.2 교체형 헤드의 의미

Head A는 우선 개발하는 광대역 현장용이다. Head B는 A의 한계가 확인된 뒤에만 검토하는 고주파 확장용이다.

교체 단위는 **코어+권선+튜닝 PCB가 결합된 전체 헤드**로 한다. 고주파 권선을 긴 전선이나 범용 핀헤더로 공용 본체에 연결하는 구조는 기본안으로 사용하지 않는다. 헤드별 교정 파일과 식별자를 유지한다.

Rev.A의 기본은 **집게형(split-core)**이다. 사용자가 선택한 방식으로, 커넥터를 분리하지 않고 케이블 중간에 열어서 장착한다. 현재 코어는 Fair-Rite 2644181281이고, A14는 외곽 손나사 두 개를 풀어 상부를 분리하는 구조다. 힌지 회전식이 아니다. C07의 앞뒤 중심 클램프를 함께 사용한다. 초기 힌지/캠안은 이력이며 현재 조립 지시가 아니다. 장착은 13절의 안전한 정지·무전원 절차를 따른다.

구경은 케이블 또는 함께 감쌀 도체군의 크기를 기준으로 잡고, 열린 상태의 진입 폭과 닫힌 상태의 유효 공간을 모두 검토한다. 커넥터는 코어 구멍을 통과시킬 필요가 없으며, 커넥터 주변에 장착할 때의 공간 간섭만 확인한다. 분할 코어 접합면의 정렬·접촉 상태와 잠금 재현성을 T05/T06에 포함한다.

## 7. 센서의 기본 모델과 설계 trade-off

### 7.1 중간 대역의 이상적 근사

일차 1턴, 이차 N턴, 이차의 유효 부담저항이 `Rb`라면 이상적인 CT의 중간 대역에서:

$$
I_s\approx\frac{I_\Sigma}{N},\qquad Z_T\approx\frac{R_b}{N}
$$

이는 충분한 자화 임피던스, 작은 누설·기생 성분, 비포화 조건의 근사다. 실제 전달 임피던스는 측정으로 확정한다.

외부 50 Ω 부담만 있다고 가정한 계산 예:

| 이차 권선 | 이상적 전달 임피던스 | 1차로 환산되는 저항 성분의 근사 |
|---|---:|---:|
| 3턴 | 16.7 Ω | 5.56 Ω |
| 5턴 | 10.0 Ω | 2.00 Ω |
| 7턴 | 7.14 Ω | 1.02 Ω |

이 표는 제품 사양이 아니라 동일 모델의 비교 계산이다.

### 7.2 저주파 한계

이차측 자화 인덕턴스를 `Lm`으로 놓은 단순 모델은 다음과 같다.

$$
Z_T(f)\approx\frac{R_b}{N}\frac{j\omega L_m}{R_b+j\omega L_m},\qquad
f_L\approx\frac{R_b}{2\pi L_m}
$$

같은 코어에서는 대략 `Lm ∝ N²`이므로 권선을 늘리면 저주파 한계를 내리는 데 유리하다. 그러나 중간 대역의 `Rb/N` 감도는 낮아지고, 기생 성분과 권선 길이도 바뀐다. **“턴 수를 늘리면 전체 감도가 좋아진다”로 단순화하지 않는다.**

### 7.3 고주파 한계

고주파에서는 권선 간 용량, 누설 인덕턴스, 코어의 복소 투자율, 차폐와의 용량, 출력 배선, 기구 공진이 함께 작용한다. 재료의 투자율은 주파수에 따라 달라지며 온도와 DC bias 영향도 받는다. [R05]

코어 카탈로그의 “노이즈 억제 대역”을 그대로 전류 센서의 평탄 측정 대역으로 가져오지 않는다. Fair-Rite 43/61 계열은 후보 재료 검토의 출발점일 뿐이며, 구체적인 형상과 측정 결과로 선정해야 한다. [R06][R07]

### 7.4 프로브가 원래 전류를 바꾼다

이차 부담은 이상적인 변압기 모델에서 대략 `Rb/N²`로 일차에 반영된다. 실제로는 코어와 기생 성분까지 더해진 주파수 의존 임피던스다. 상용 전류 모니터도 삽입 저항을 별도 항목으로 다룬다. [R08]

따라서 비접촉이라는 이유만으로 비침습이라고 단정하지 않는다. 감도를 높이기 위해 턴 수를 줄였더니 공통모드 전류 자체가 줄어드는 상황을 반드시 확인한다.

### 7.5 DC가 출력되지 않아도 코어는 영향을 받는다

CT 출력에 DC가 나타나지 않는 것과 DC 전류가 코어에 영향을 주지 않는 것은 다르다. 상쇄되지 않은 DC 또는 큰 저주파 전류는 코어의 동작점을 바꾸고 RF 감도를 저하시킬 수 있다. [R05]

따라서 +24 V 한 선만 넣고 “DC는 안 보이니 RF만 잘 측정된다”고 가정하지 않는다. 공통모드 측정에서는 해당 부하의 정상 왕복 도체를 함께 통과시키고, 다른 경로로 돌아가는 전류가 있는지 확인한다. 허용 순 DC 전류와 저주파 전류는 실측 전까지 `TBD`다.

## 8. 코어·권선·차폐 선택 절차

### 8.1 코어 선정표에 필요한 정보

에이전트는 최대 2~3개 후보부터 검토한다. 처음부터 많은 코어와 헤드를 동시에 발주하지 않는다.

후보마다 제조사/부품번호, 재료, 내경·외경·높이, 절연 및 코팅, 투자율 자료의 유효 주파수, AL 또는 등가 인덕턴스 정보, 가격·재고 확인일, 가공 가능성을 기록한다.

집게형 후보에는 분할 코어의 조합·접합면, 권선 가능 공간, 열림·잠금 구조를 추가한다. 이전 닫힌 코어의 AL이나 치수 계산을 분할 코어에 그대로 적용하지 않는다.

재료명만 같다고 다른 제조사의 복소 투자율을 그대로 대입하지 않는다. 모델 자료가 없으면 `모델 불확실 — 실측 우선`으로 적는다.

### 8.2 초기 실험

가능하면 코어 소수에 대해 3/5/7턴을 순차적으로 감아 비교한다. 이 수치는 탐색 시작점이며 설계 확정값이 아니다. 매번 권선 방향·도선 종류·배치·리드 길이·차폐 상태를 사진과 함께 기록한다.

한 번에 바꾸는 변수를 제한한다. 코어, 턴 수, 차폐, 튜닝 부품을 동시에 바꾼 뒤 어느 요인이 좋아졌다고 해석하지 않는다.

### 8.3 차폐

차폐의 목적은 권선에 직접 결합하는 전기장 픽업을 줄이는 것이다. 그러나 차폐·나사·PCB 동박·SMA 외피가 결합해 **코어 자속을 쇄교하는 단락 1턴**을 만들면 안 된다.

필요한 절연 갭은 완성된 3차원 전류 경로에서 검토한다. “어딘가 한 군데 잘랐으니 안전하다”거나 “모든 원형 동박은 금지다”로 처리하지 않는다. 코어 구멍을 통과했다가 바깥으로 돌아오는 도전 루프가 형성되는지 확인한다.

헤드의 기준 차폐 접속은 RF ground/출력 동축 외피로 정의하되, DUT 쉴드나 샤시에 추가로 연결하지 않는다. 차폐와 계측기 접지는 실제 전기적 경로의 일부이므로 접속 방식을 도면에 표시한다. 상용 모니터도 차폐 및 장착부의 접지 구성을 명시한다. [R09]

## 9. Probe Head PCB 설계 지침

### 9.1 기본 회로

**권선의 신호단 → 최소한의 선택형 직렬/감쇠 경로 → SMA 중심도체**

**권선 귀환단 → 정의된 RF ground → SMA 외피**

현행 Head A04는 권선 패드와 SMA를 직접 동박으로 연결한다. 직렬 0 Ω 및 션트 RC 실장 위치나 헤드의 병렬 50 Ω 종단은 없다. 초기 선택 패드안은 채택하지 않았다. 추가 보상망이 필요해지면 별도 회로 변경으로 검토하며 기존 교정을 그대로 사용하지 않는다.

50 Ω 종단이 있다고 해서 권선의 신호·귀환을 각각 50 Ω 전송선으로 만들어야 한다는 뜻은 아니다. 권선에서 SMA까지의 구간을 짧게 유지하고, 전송선으로 취급하는 구간에는 실제 제작 stack-up을 사용한다.

### 9.2 종단의 기본 결정

기본안은 **수신기 쪽에 하나의 50 Ω 종단**을 둔다.

- 오실로스코프에 유효한 50 Ω 입력이 있으면 이를 사용한다.
- 1 MΩ 입력만 있으면 오실로스코프 입력 커넥터에 규격에 맞는 50 Ω feed-through 종단을 연결한다.
- 헤드 PCB에는 상시 49.9 Ω 션트를 기본 장착하지 않는다.

이 방식은 50 Ω로 교정한 RF current probe를 오실로스코프에 연결하는 제조사 안내와 일치한다. [R03]

헤드의 내부 부담저항과 외부 종단을 병용하는 다른 회로도 가능하지만, 별도 회로 변형으로 취급한다. **헤드에 50 Ω 저항을 붙이고 긴 동축 끝은 1 MΩ으로 두는 구성을 기본 50 Ω 측정계와 같다고 취급하지 않는다.**

### 9.3 레이아웃

작은 출력 PCB는 2층을 우선 검토한다. 4층이 필요하면 실제 return-path·차폐·기구상의 이득을 기록한다. 레이어 수 자체를 RF 성능의 근거로 쓰지 않는다.

제조사 stack-up과 SMA footprint를 확인한 뒤 선폭을 계산한다. 기존 Ethernet 지그의 100 Ω 차동 패턴 폭을 이 보드에 복사하지 않는다.

출력 신호의 귀환 경로는 연속적으로 제공하되, 코어·차폐 주변에서는 단락 턴을 만들지 않도록 전체 경로를 검토한다. 긴 테스트포인트 가지, 불필요한 via, 권선 근처의 과도한 동박 면적을 피한다.

DNP 부품도 패드와 분기 배선의 기생 성분은 남는다. 각 옵션은 실제로 필요한 이유가 있을 때만 배치한다.

### 9.4 기구

실효 구경은 코어 내부 공간에서 권선·절연·하우징 간섭을 제외한 값이다. 집게형에서는 실제 케이블/다발의 굵기와 열린 상태의 진입 폭으로 장착 가능성을 확인한다. M12/RJ45 커넥터의 부트·래치·너트는 인접 설치 공간의 간섭 검토 대상으로 다룬다.

도체 위치를 반복해서 재현할 수 있는 비도전성 스페이서를 둔다. 코어에 과도한 체결 하중을 주지 않으며, SMA 체결력이 권선 접속부에 직접 전달되지 않도록 한다.

외형에 헤드 ID, 권선 극성 기준, 검증된 대역, 사용 부하를 표시할 자리를 확보한다. 제작 전에는 검증 완료 라벨을 넣지 않는다.

## 10. 교정지그 — 가장 먼저 검증할 부분

### 10.1 올바른 전류 경로

**VNA P1 → 지그 중심 도체 → 50 Ω 종단 → 코어 바깥의 귀환 구조 → VNA P1 외피**

**프로브 SMA → VNA P2**

중심 도체만 코어 구멍을 관통시키고 귀환 경로는 코어 바깥으로 보낸다. Tekbox의 교정지그 역시 중심 도체와 외부 귀환 구조를 갖춘 약 50 Ω 동축형 구조를 사용한다. [R02]

**금지되는 기본 오해:** 일반 microstrip PCB의 신호선과 바로 아래 GND를 함께 코어 구멍에 넣으면, 정상 신호전류와 귀환전류가 상쇄되어 의도한 교정 전류가 보이지 않을 수 있다. 동축 케이블 전체를 통째로 통과시키는 경우도 같다.

그 구성에서 큰 출력이 나오면 오히려 외피 전류·전기장 픽업·불균형을 의심해야 한다. 그것을 바로 전류 감도로 계산하지 않는다.

### 10.2 현실적인 구현

Fixture A04/A05는 중앙 SIG와 코어 밖 귀환을 평판 PCB에 구현한 보존 후보다. 4층 A04는 SMA 부근 L1 SIG 아래에 L2 귀환을 유지하고 중앙15.0 mm에서 제거했으며, A05는 중앙 SIG 폭과 평판 리턴 위치를 바꿨다. 이 구조는 올바른 전류 방향을 만들지만100–500 MHz 정합을 만들지는 못했다. A04의 전체 openEMS S11은100 MHz 약−14…−16 dB,500 MHz 약−1 dB였고 A05 coarse도500 MHz 약−4 dB였다.

두꺼운 SIG 블록·쐐기·이상 외함을 소수 비교해도400–500 MHz 반사는 남았다. 260–300 MHz의 깊은 S11은 양쪽 불연속의 위상 상쇄이며 광대역 정합 근거가 아니다. 일정 단면 외함 계산에서는20–26 mm 전류 바가 약69–85 Ω였고, 빈 구조를−20 dB에 가깝게 만들려면32–34 mm 바가 필요해 공칭26 mm 구경과 충돌했다.

따라서100–500 MHz 절대 교정에는 현재 A14에 평판 PCB를 반복 수정하지 않는다. 프로브를 설치한 상태까지 포함한 일정 단면 금속 지그와 더 작은 교정 전용 캐리어를 별도로 개발·의뢰하거나, 기존 지그를 VNA로 측정해 검증된 범위의 상대 특성화에만 사용한다. JLC의50 Ω 제어 임피던스는 SMA launch를 관리할 뿐 중앙 무리턴 구간과 완성 지그를 보증하지 않는다. 근거와 중지 판정은 [교정지그 구조 재검토](../reviews/fixture_structural_redesign_20260922/ENGINEERING.md)를 따른다.

처음 만든 단순 루프 지그가 저주파에서만 충분히 유효하면 그 범위에서 먼저 비교 실험을 진행한다. 300/500 MHz까지 검증하지 못한 루프를 광대역 절대 교정지그라고 부르지 않는다.

### 10.3 별도로 검증할 세 가지

1. **Through 경로:** P1 → 지그 → P2로 연결해 지그의 반사·손실·위상 특성을 확인한다.
2. **헤드가 장착된 상태의 경로:** 헤드 출력을 50 Ω로 종단하고 다시 측정하여 일차 경로의 변화량을 확인한다.
3. **직접 누설:** 프로브의 의도한 자기 결합을 제거한 대조 구성에서도 P1 신호가 P2로 얼마나 새는지 확인한다.

지그의 좋은 S11만으로 코어 위치의 전류와 위상까지 완전히 안다고 간주하지 않는다. 손실·분기 용량·도체 위치·헤드 부하를 포함해 판단한다.

## 11. 전달 임피던스의 계산과 교정 절차

### 11.1 정합된 지그의 근사식

전제는 다음과 같다.

- 두 VNA 포트의 기준 임피던스가 동일한 실수 50 Ω이다.
- 지그가 충분히 정합되어 있으며 코어 위치의 일차 전류를 입력 진행파로 근사할 수 있다.
- 케이블 손실과 기준면이 정리되어 있다.
- 출력 부하는 교정에 사용한 50 Ω이다.

이 조건에서 크기는 다음과 같이 계산할 수 있다.

$$
|Z_T|\approx Z_0|S_{21}|=50|S_{21}|\ \Omega
$$

$$
Z_T[\mathrm{dB\Omega}]\approx S_{21}[\mathrm{dB}]+33.9794
$$

이는 알려진 50 Ω 교정지그에서 사용하는 약 `S21+34 dB` 관계다. **임의의 불정합 루프에 조건 없이 적용하는 공식이 아니다.** [R02]

예를 들어 교정 S21이 −20 dB이면 `|S21|=0.1`, `|ZT|=5 Ω`, `ZT≈13.98 dBΩ`이다. 이 숫자는 분석 도구의 기본 단위시험으로 사용한다.

### 11.2 불정합 보정은 기준면이 먼저다

일차 전류가 정의되는 위치와 VNA 기준면이 같고, 그 사이에 분기 전류가 없는 모델에서는:

$$
I_\Sigma=\frac{a_1-b_1}{\sqrt{Z_0}},\qquad
Z_T=Z_0\frac{S_{21}}{1-S_{11}}
$$

일반적인 지그에서는 이 조건이 자동으로 충족되지 않는다. 코어 앞의 선로 지연, 지그의 분포정수 구조, 누설·기생 용량을 정리하지 않은 채 입력단 S11로 일괄 보정하지 않는다.

더 일반적으로 코어 위치 전류와 입력 진행파 사이의 관계를 `HI(f)=IΣ/a1`로 정의하면:

$$
Z_T(f)=\frac{\sqrt{Z_0}\,S_{21}(f)}{H_I(f)}
$$

`HI`를 신뢰성 있게 구하지 못했으면 절대 전류 교정이 아닌 **지그 고정 조건의 상대 특성화**로 분류한다.

### 11.3 위상

파형 복원까지 하려면 복소 `ZT(f)`가 필요하다. 50 Ω 근사식으로 크기가 맞더라도 지그에서 코어까지의 위상 지연이 자동으로 제거되는 것은 아니다. 교정 기준면과 지연 모델을 함께 저장한다.

### 11.4 실행 순서

1. VNA 예열·케이블 고정·버전·출력 레벨·IF bandwidth·평균·주파수 점을 기록한다.
2. 사용 케이블 끝에서 지원되는 적절한 2-port 교정을 수행한다. 단순 through 정규화만 사용했다면 그 사실을 명시한다.
3. 지그의 through 경로와 헤드 부하에 따른 변화를 확인한다.
4. P1은 지그 입력, 지그 끝은 50 Ω 종단, P2는 프로브 출력으로 바꾼다.
5. 주파수별 복소 S-parameter를 저장한다. 출력 레벨을 바꿔 선형성을 확인한다.
6. 적용 가능한 지그 모델로 `ZT`를 구하고 유효하지 않은 구간은 마스킹한다.
7. 헤드 탈착·재장착, 도체 위치 변경, 다시 원위치 복귀를 반복한다.
8. 실제 사용할 출력 케이블·감쇠기·보호 부품을 포함한 체인도 같은 기준으로 특성화한다.

### 11.5 공식 복사 시 주의

[R02]의 2쪽에는 전력 차로 쓴 식의 부호가 같은 페이지의 `S21+34` 식과 일치하지 않는 부분이 있다. 본 프로젝트는 다음 정의로 검산한다.

`S21[dB] = Pout[dBm] − Pin[dBm]` — 동일 기준 임피던스와 정합 조건.

따라서 위 조건의 전력 차 표현은 `Pout − Pin + 33.9794`이다. 제조사 문서라는 이유만으로 모순된 식까지 그대로 코드에 복사하지 않는다.

## 12. 오실로스코프 측정과 전류 환산

### 12.1 먼저 확인할 장비 정보

오실로스코프의 정확한 모델, 아날로그 대역폭, 50 Ω 입력 유무, 각 입력 모드의 최대 전압/전력, 샘플링 속도, 메모리와 트리거 기능, 파일 저장 방식을 기록한다. 모르는 사양은 추정하지 않는다.

**프로브가 300 MHz까지 특성화되어도 오실로스코프가 같은 대역을 시간 파형으로 보장하는 것은 아니다.** 계측기와 케이블·보호장치가 전체 측정 대역의 일부다.

### 12.2 주파수별 전류

수신기 입력까지 실제 체인의 전달 임피던스를 `ZT,chain`이라 할 때:

$$
I_\Sigma(f)=\frac{V_{receiver}(f)}{Z_{T,chain}(f)}
$$

여기서 체인 교정은 수신기 입력 커넥터까지를 뜻한다. 오실로스코프 내부의 주파수 응답이 VNA 교정으로 자동 보정되는 것은 아니다.

$$
I[\mathrm{dB\mu A}]=V[\mathrm{dB\mu V}]-Z_T[\mathrm{dB\Omega}]
$$

50 Ω에서 RMS 전력을 사용하는 경우에는 `V[dBµV]=P[dBm]+106.99`이다. 전압의 peak/RMS/peak-to-peak 정의는 반드시 일치시킨다.

계산 예로 `ZT=5 Ω`이면 1 mA RMS 정현파는 5 mV RMS 출력에 해당한다. 이 예는 최소 검출 성능을 보장하지 않는다.

### 12.3 과도 파형

넓은 대역의 펄스에 대해 오실로스코프 최대 전압을 임의의 한 주파수의 `ZT`로 나누어 “실제 피크 전류”라고 표시하지 않는다.

시간 파형 복원은 복소 응답과 위상, 계측기 응답, 유효 대역, 노이즈 제한을 갖춘 별도 기능이다. 깊은 null 부근에서 단순 역필터링하면 노이즈를 크게 증폭한다. DC와 측정 대역 밖 성분은 복원할 수 없으므로 결과를 **대역 제한된 추정 전류**로 표시한다.

CT의 저주파 차단 때문에 긴 펄스는 droop와 기준선 변형을 보일 수 있다. 실제 전류가 일정한 구간에서도 출력이 0 방향으로 내려갈 수 있다. [R10]

Rev.A에서는 우선 원시 전압 파형, 이벤트 시각, 특정 대역의 크기 변화를 신뢰성 있게 저장한다. 파형 역복원은 이 기능이 검증된 뒤 추가한다.

## 13. 계측기 보호와 사용 금지 범위

이 프로브는 현장 포트 손상이 의심되는 환경에 사용할 예정이므로, 센서뿐 아니라 **수신기 입력 보호**를 시스템의 일부로 취급한다.

### 13.1 기본 원칙

- 실험실의 제한된 저에너지 신호로 헤드와 교정지그부터 검증한다.
- 초기 적용은 절연 상태와 전류 경로가 확인된 저전압 하네스로 제한한다.
- 헤드 장착과 배선 변경은 장비의 안전한 정지·무전원 절차를 따른다.
- 코어가 케이블을 감싼 상태에서 2차 출력을 함부로 개방하지 않는다. 정의된 부담/종단을 유지한다.
- 계측기 PE를 제거하거나, 접지형 오실로스코프를 임의로 부유시키지 않는다.

### 13.2 수동 센서도 안전 인증품은 아니다

권선과 일차 케이블 사이에 도전 접속이 없더라도 절연 파괴·전기장 결합·예상 밖의 출력 전압에 대한 안전이 자동 보장되지는 않는다. 고전압용 상용 전류 모니터도 구경·전계·차폐·접지 구조를 별도로 고려한다. [R11]

**Rev.A를 상용전원, VFD 출력선, 노출 고전압 도체, 낙뢰/서지 시험에 직접 적용하지 않는다.** 이런 범용 확장은 별도 절연·포화·열·정격 검토가 끝난 뒤의 과제다. 안전 정격을 만들지 못한 상태에서 “CAT III” 등의 표시를 쓰지 않는다.

### 13.3 보호 체인

외부 RF 감쇠기와 필요한 제한 회로의 허용 RF 전력, 펄스 에너지, 전압, 주파수 응답을 확인한다. 감쇠기가 있다는 이유만으로 서지 보호가 충분하다고 간주하지 않는다.

보호 소자가 클리핑한 파형은 전류의 원형이 아니다. 분석 결과에 `CLIPPED/OVERLOAD` 상태를 남긴다. 대역 밖의 큰 저주파 성분도 수신기를 과부하시킬 수 있다. [R03]

LibreVNA는 우선 **안전한 실험실 교정용**으로 사용한다. 현장 미확인 과도전류를 처음 발견하는 수신기로 바로 연결하지 않는다.

| T12 | 현장 전후 상태 점검 | 동일 지그 재측정으로 손상·특성 변화 확인 |

T07에서 귀환선을 옮기면 시험 회로의 임피던스와 전류 자체도 달라질 수 있다. 같은 소스 설정만으로 동일 일차 전류라고 가정하지 말고 지그 특성 또는 별도 기준으로 정규화한다.

20 dB 상쇄는 구조가 동작하는지 보는 시작 기준이지 작은 CM 전류를 정확히 구별한다는 보장이 아니다. 예를 들어 10 mA의 왕복 RF 전류가 20 dB만 억제되면 약 1 mA 상당의 잔류 출력이 남을 수 있다. 그 구성에서 1 mA CM을 관측했다고 단정할 수 없다. 실제 사용 시에는 예상 DM 전류와 목표 CM 전류의 비율을 기준으로 필요한 상쇄 성능을 다시 정한다.

T08의 대조 구성 예는 중심 도체가 코어를 통과하지 않는 상태, 2차 입력을 같은 기하구조로 대체 종단한 상태 등이다. 대조 결과가 순수한 E-field 성분만을 완벽히 분리한다고 주장하지 않는다.

### 14.2 유효 대역의 정의

주파수 한 점이 다음 조건을 모두 만족할 때만 전류 환산의 유효 구간에 포함한다.

- 신호가 수신기 잡음 바닥과 직접 픽업보다 충분히 크다.
- 선형 동작이며 클리핑·포화가 없다.
- 지그의 전류 모델과 기준면이 유효하다.
- 반복성과 위치 오차가 허용 범위다.
- 보정이 불안정해지는 깊은 null이 없다.

검출용 최소 SNR은 10 dB를 초기 기준으로 삼되, 이것만으로 절대 정확도를 보장하지 않는다. 잡음 바닥에는 측정 bandwidth, 평균, FFT window/ENBW 등 조건을 붙인다.

검증된 대역이 두 구간으로 나뉘면 두 구간으로 보고한다. 중간의 결손을 보간으로 메워 “100 kHz~500 MHz”라고 표시하지 않는다.

### 14.3 정확도 등급

| 등급 | 허용되는 표현 |
|---|---|
| A — 비교용 | 같은 지그·같은 체인에서 상대 변화 측정 가능 |
| B — 전류 추정용 | 지그 전류 모델과 오차 예산이 확보된 유효 대역에서 전류 추정 가능 |
| C — 검증된 정량용 | 독립 기준과 비교한 정확도·재현성 범위가 제시됨 |

Rev.A는 먼저 A, 이후 B를 확보한다. 1~100 MHz에서 ±3 dB 수준의 정량 오차 예산을 초기 목표로 검토할 수 있으나, 입증 전에는 성능표에 넣지 않는다. 추적성 있는 교정이 없으면 정식 교정성적서처럼 표현하지 않는다.

### 14.4 오차 예산

지그 전류 오차, VNA 교정 오차, 출력 체인의 불정합, 누설·픽업, 재장착, 도체 위치, 온도, 수신기 잡음·대역폭을 구분한다. 독립성이 확인되지 않은 오차를 무조건 RSS로 합쳐 오차가 작아 보이게 만들지 않는다.

## 15. 현장 측정 절차

### 15.1 실험 조건을 실제로 분리한다

“회전 ON / 모든 전원 OFF”처럼 물리적으로 실행 불가능한 조건을 표에 넣지 않는다. DUT 전원, 회전 구동기, 주변 설비의 상태를 별도 변수로 둔다.

| 조건 | DUT | 회전 구동 | 주변 설비 |
|---|---|---|---|
| F0 | 무전원 | 정지 | 가능한 한 정지 — 주변 픽업 기준 |
| F1 | 동작 | 정지 | 가능한 한 정지 — 기준 상태 |
| F2 | 동작 | 실제 회전 | F1과 동일하게 유지 가능한 범위 |
| F3 | 동작 | 정지 | 문제와 연관된 주변 설비 동작 |
| F4 | 동작 | 실제 회전 | F3과 동일한 주변 설비 동작 |

주변 설비를 통제할 수 없으면 그 사실과 가동 상태를 기록한다. F2에서 증가했다고 바로 슬립링 접촉 불량으로 확정하지 않는다. 회전 모터와 구동기 자체가 추가된 조건이기 때문이다.

### 15.2 위치 순서

전체 하네스 → 접근 가능한 Ethernet 도체군/한 페어 → 전원 도체군 → 접근 가능한 쉴드 접속 경로 순서로 진행한다.

측정 위치의 커넥터까지 거리, 도체 배치, 헤드 방향, 출력 동축의 경로를 표시한다. 케이블의 서로 다른 위치는 같은 전류값을 보장하지 않으므로 위치를 바꾸면 별도 조건이다.

### 15.3 오류와 동시 기록

가능한 로그는 다음과 같다.

`RF waveform/이벤트 시각 + 회전각/속도 + PHY CRC/Symbol/Link 상태 + 장비 uptime/reset + UDP 순번·관측 시각`

PHY 카운터의 clear-on-read, wrap, 읽기 주기를 기록한다. 카운터를 100 ms마다 읽었다면 그보다 짧은 사건의 선후 관계를 정확히 안다고 표현하지 않는다.

오실로스코프가 pre-trigger나 segmented capture를 지원하면 활용하고, 미지원 기능을 전제로 계획하지 않는다. 로그 간 시계 관계와 동기화 오차를 기록한다. 프로브 하나를 옮겨 측정한 여러 위치의 결과는 동시 측정이 아니다.

### 15.4 해석 기준

| 관측 | 다음 판단 |
|---|---|
| RF 전류 이벤트가 오류와 반복적으로 겹침 | 해당 경로의 연관성 증가. 배치·차폐 등 통제된 A/B로 확인 |
| 큰 전류가 있으나 오류 없음 | 크기만으로 고장 임계값을 만들지 않음. 주파수·유입 위치·변환 경로 조사 |
| 전체는 작고 특정 도체군은 큼 | 내부 귀환/상쇄 가능성. 다른 경로와 구분하여 조사 |
| 프로브를 달면 오류가 사라짐 | 프로브의 부하 또는 접지·기생 결합이 현상을 바꿨을 가능성 |
| 전류 변화가 관측되지 않는데 오류 발생 | 대역·트리거 누락·상쇄·다른 경로를 검토한 뒤 SI/전원/SW 조사 병행 |

UDP 버스트만을 RF 마진의 지표로 사용하지 않는다. 실제 패킷이 선로에서 늦게 나간 것인지, 수신기·OS·애플리케이션에서 늦게 관측된 것인지 분리한다.

## 16. 분석 도구와 데이터 계약

### 16.1 기본 구현

Python 기반으로 재현 가능한 오프라인 분석을 먼저 만든다. GUI나 실시간 대시보드보다 입력 검증·단위·교정 이력을 우선한다.

Touchstone 처리에는 검증된 라이브러리 사용을 우선하고, 지원 버전과 API는 설치 환경에서 확인한다. 자체 파서를 만든다면 형식·단위·포트 순서에 대한 충분한 테스트가 선행되어야 한다.

### 16.2 향후 저장 구조

### 16.3 측정 메타데이터

최소 필드:

`measurement_id`, `head_id`, `head_revision`, `core_part`, `turns`, `shield_revision`, `fixture_id`, `calibration_id`, `cable_ids`, `receiver_model`, `termination`, `attenuation_profile`, `source_level`, `frequency_range`, `if_bandwidth`, `averaging`, `temperature`, `conductor_position`, `timestamp`, `data_kind`.

현장 기록에는 측정 도체 구성, 쉴드 포함 여부, DUT/회전/주변 설비 상태, 로그 시계 오차, 클리핑 여부를 추가한다.

`data_kind`는 `MEASURED`, `SIMULATED`, `SYNTHETIC` 중 하나로 명시한다. 합성 데이터는 실제 측정 폴더와 구분한다.

### 16.4 교정 결과 파일

CSV의 권장 열:

`frequency_hz, zt_real_ohm, zt_imag_ohm, zt_magnitude_ohm, zt_db_ohm, phase_deg, valid, uncertainty_db, quality_flag`

불확도가 미평가이면 0을 넣지 않고 빈 값과 `UNASSESSED` 상태를 사용한다. 위상이 유효하지 않으면 복소값을 임의로 채우지 말고 magnitude-only 등급으로 저장한다.

### 16.5 필수 소프트웨어 시험

- `S21=-20 dB`, 정합 50 Ω 예제에서 `ZT=5 Ω`를 재현한다.
- 기준면 조건이 맞는 합성 모델에서만 `1−S11` 보정을 검증한다.
- Hz/kHz/MHz, RI/MA/DB 형식과 포트 순서를 검증한다.
- 50 Ω가 아닌 기준 임피던스 입력은 명시적으로 처리하거나 거부한다.
- peak/RMS/peak-to-peak 및 dBm/dBµV/dBµA 환산을 검증한다.
- 교정 대역 밖 외삽, null 부근 역보정, 클리핑 데이터 정량화를 차단한다.
- 교정 체인에 포함한 케이블/감쇠기를 다시 보정하는 이중 보정을 차단한다.
- 합성·실측 데이터와 불확도 미평가 상태를 플롯에도 표시한다.

각 플롯에는 축·단위·헤드·교정 ID·유효 대역을 표시한다. 서로 다른 항목을 보기 위해 불필요한 3D 시각화를 만들지 않는다.

## 17. 시뮬레이션의 역할

첫 도구는 등가회로와 파라미터 sweep이다. 코어의 자화·손실, 누설 인덕턴스, 권선 용량, 차폐 용량, 부담저항, 출력 기생 성분을 분리해 감도와 한계를 확인한다.

openEMS 등 전자기 시뮬레이션은 교정지그의 구조·반사·직접 결합이나 PCB/차폐 기구 검토가 실제 의사결정을 바꿀 때 사용한다. 전체 프로브를 처음부터 큰 3D 모델로 만드는 것을 선행 조건으로 두지 않는다.

특히 코어의 주파수 의존 복소 투자율 자료와 해석기의 재료 모델 지원 범위를 확인하지 않고 상수 투자율 모델로 300 MHz 성능을 보장하지 않는다. 수렴 시험·메시·경계 조건·재료 출처가 없는 결과를 설계 검증으로 분류하지 않는다.

**시뮬레이션은 후보를 줄이는 도구이며, 실제 권선·차폐·기구를 포함한 프로브의 최종 검증은 측정이다.**

## 18. 예산과 범위 관리

신규 지출에는 코어, 도선·절연·차폐, PCB 제작과 배송, SMA/동축/어댑터, 종단, 필요한 보호 부품, 기구물과 재작업 여유를 포함한다. 이미 보유한 LibreVNA와 오실로스코프 가격은 제외한다.

이 문서는 총액을 보장하는 BOM 견적서가 아니다. 10만 원 목표 및 20만 원 상한 안에서 가능한지 부품 선정 단계에서 확인한다. 환율·배송·부가세·재고는 구매 시점의 정보로 갱신한다.

예산이 넘으면 **두 번째 헤드, 고급 케이스, 자동화 UI, 500 MHz 확장**을 먼저 줄인다. 종단·계측기 보호·기본 검증을 예산 때문에 생략하지 않는다.

안전한 측정 체인을 상한 안에 구성할 수 없으면 현장 사용 범위를 제한하고 사유를 보고한다. 별도 수신기 구매가 필요해졌다면 프로브 비용과 혼합하지 말고 분리해서 승인을 받는다.

## 19. 구현 에이전트의 단계별 실행 지침

### G0 — 착수와 미확정 사항 분리

저장소와 기존 KiCad/분석 파일을 먼저 조사한다. 존재하는 사용자 작업을 덮어쓰지 않는다. 이 문서의 요구사항을 표로 만들고, 각 항목을 알려진 사실·가정·실측 필요·사용자 확인 필요로 나눈다.

우선 확인 항목은 실제 케이블/다발 굵기, 집게형의 열림·잠금 공간과 인접 커넥터 간섭, 오실로스코프 모델/입력, 보유 RF 종단·동축·감쇠기, LibreVNA의 실제 버전이다.

**종료 조건:** `STATUS.md`, `REQUIREMENTS.csv`, 기존 파일 목록과 비파괴 작업 계획이 있다. 정보가 부족해도 안전한 조사·계산은 계속하되 제조 승인이나 현장 안전 승인은 보류한다.

### G1 — 센서와 교정 토폴로지 검토

집게형에 적용 가능한 분할 코어 2~3개 후보와 3/5/7턴 시작점을 비교한다. 앞서 제시한 감도·저주파 차단·삽입 영향 모델을 적용하되 데이터 부족을 표시한다. 분할면과 잠금 상태를 모델·실험 조건에 포함한다.

교정지그의 중심 전류와 귀환 경로, 출력 동축의 경로를 도면 또는 명료한 구조 설명으로 제출한다. “PCB 신호+GND가 함께 코어를 통과하는” 오류가 없는지 별도 검토한다.

**종료 조건:** 권고 후보 한 가지와 대안, 가정 범위, 부품 출처, 비용표, 교정의 유효 조건과 계산 검산이 있다.

### G2 — 최소 실험과 특성화 도구

가능한 한 간단한 헤드·저에너지 교정 구성으로 방향성을 확인한다. 실제 하드웨어에 접근할 수 없는 에이전트는 조립·측정 절차와 분석 코드를 준비하되 실측했다고 보고하지 않는다.

분석 도구와 합성 데이터 단위시험을 만든다. 파일 형식·단위·기준면·invalid mask를 먼저 검증한다.

**종료 조건:** 실험 가능한 최소 구성과 재현 가능한 분석 도구가 있다. 실측 여부는 별도로 표시한다.

### G3 — 회로·PCB·기구 상세 설계

확인된 코어와 기구 조건을 바탕으로 KiCad 원본을 만든다. 불필요한 확장 회로를 넣지 않는다. 회로도·PCB·BOM·조립도·종단 구성·차폐 경로가 일치해야 한다.

설치된 KiCad 버전에서 지원하는 검증/내보내기 명령을 확인하고 실행한다. ERC/DRC의 실행 로그와 미해결 항목을 남긴다. DRC 통과를 RF 성능 검증으로 표현하지 않는다.

**종료 조건:** 제작 검토가 가능한 원본과 보고서가 있다. 구경/절연/보호 조건 미확정이면 `DRAFT — NOT FOR FABRICATION` 상태다.

### G4 — 벤치 검증

T01~T11을 수행하거나 수행할 수 있도록 절차를 제공한다. 각 요구사항에 실제 파일·시험 결과를 연결한다. 실패 구간도 보존한다.

**종료 조건:** 유효 대역과 측정 등급, 반복성, 삽입 영향, 남은 한계가 명시된다. 목표 미달이면 범위를 축소하거나 설계를 수정한다.

### G5 — 제한된 현장 적용

입력 보호와 장착 안전을 확인한 뒤 F0~F4 중 실행 가능한 조건을 수행한다. 장애 이벤트와 RF 전류를 시간축으로 비교하고, 전후 교정 점검을 수행한다.

**종료 조건:** 관측 사실, 지지되는 가설, 배제하지 못한 항목, 다음 한 가지 실험을 구분한 보고서가 있다. 단순 상관을 원인 확정으로 표시하지 않는다.

### G6 — 확장 여부 결정

Head A가 유효한 도구가 된 뒤에만 더 높은 대역, 별도 HF 헤드, 편의 기능을 추가한다. 집게형은 0.2 개정부터 Rev.A의 기본 범위다. PCB 근처의 국소장을 탐색하는 H-field loop probe는 다른 측정 도구이므로 별도 사양과 교정 체계를 사용한다.

## 20. 변경·검토·완료 보고 규칙

### 20.1 변경 관리

`DECISIONS.md`에는 날짜, 변경 항목, 이전 결정, 새 결정, 근거, 영향받는 요구사항, 재시험 항목을 남긴다.

코어, 턴 수, 권선 배치, 차폐, PCB 튜닝, 출력 케이블·종단·보호 체인이 달라지면 교정의 재사용 가능성을 검토한다. 같은 이름의 CSV를 덮어써 이력을 지우지 않는다.

### 20.2 에이전트가 하지 말아야 할 것

- 미실행한 ERC/DRC·시뮬레이션·측정을 통과했다고 쓰지 않는다.
- 데이터시트의 기능·주파수 범위·가격·핀맵을 추측해 채우지 않는다.
- 실측 없는 300/500 MHz 성능표, 허용 전류, 내전압을 만들지 않는다.
- 기존 대화의 7턴·구경·비용 추정을 확정 사양으로 고정하지 않는다.
- 분석 프로그램이 정상 실행된 것을 센서 검증 완료로 표현하지 않는다.
- 요구사항을 만족시키기 위해 정상 보호접지·쉴드·케이블 구조를 임의로 제거하지 않는다.

### 20.3 단계 종료 보고 형식

`완료한 작업 → 생성/변경 파일 → 실제 실행한 검증 → 미검증·막힌 항목 → 다음 단계`

실물 측정이 남아 있으면 구체적으로 무엇을 연결하고 어떤 파일을 얻어야 하는지 적는다. 에이전트가 직접 실행할 수 없는 실험과 안전 승인은 인간 작업으로 구분한다.

### 20.4 최종 완료의 정의

프로젝트가 완료되었다고 말하려면 다음이 함께 있어야 한다.

**재제작 가능한 원본 + 조립/측정 절차 + 개체별 교정 데이터 + 유효 대역/한계 + 검증 기록 + 계측기 보호 조건.**

이 중 하나라도 빠지면 상태는 그 단계까지의 설계 또는 시제품이다.

| `V = 5 mV RMS`, 50 Ω | `P ≈ −33.0103 dBm` |
| `V = 5 mV RMS` | `V ≈ 73.9794 dBµV` |
