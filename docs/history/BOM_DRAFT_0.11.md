## 2. 연결 및 교정 조건

**2026-09-17 수량 보완:** 집게는 [A0.2](../mechanical/clamp_A02_DRAFT/README.md) 스토퍼 형상으로 진행하며 일반 헤드 부속 수량은 A0.1과 같다. 지그에 추가되는 나일론 M3×12 6개, M3×10 4개, M3 nut 10개, M2×20 2개, M2 nut 2개, 발 4개를 FIX-MECH-01에 등록한다. M2×20 두 개는 벤치에서 기존 PCB M2×10 두 개를 교체한다. SMA 자체 nut/washer와 나일론 nut를 혼동하지 않는다. 기존 지그 비용 배정에 이 상세 목록을 대입해 실견적을 다시 산출하며 이중 합산하지 않는다. [현재 구매 준비의 막힘](BUILD_READINESS_20260917.md).

- 현재 안은 `헤드 SMA → 정의된 50 Ω 동축·보호/감쇠 체인 → MSO4054의 BNC 아날로그 입력(내부 50 Ω)`이다. 케이블과 보호 부품의 물리적 순서·단자 성별은 체인 설계에서 일치시킨다.
- SMA–BNC 완제품 케이블을 사용하면 **오실로 접속을 위한 별도 변환 어댑터를 중복 계상하지 않는다.** 단순 수동 신호 연결을 위해 능동 TekVPI 프로브 어댑터를 기본 BOM에 추가하지 않는다.
- 사용 장비가 MSO4054이고 내장 50 Ω를 사용할 수 있으면, 외부 50 Ω feed-through 종단을 병렬로 추가하지 않는다. 지그의 일차 경로 끝에 필요한 50 Ω 부하는 별개다.
- 케이블 길이·부품번호·보호 체인이 정해지면 식별자를 부여하고 실제 체인의 손실·위상·반사 및 교정 이력을 관리한다. 케이블 교정이 포함된 결과에 다시 같은 손실 보정을 적용하지 않는다.
- **교정 연결:** ADAPT-CAL-01은 BNC-F/SMA-F가 기준이다. 종전 BNC-F/SMA-M은 male–male CAB-P2와 연결되지 않는다. SMA-M형을 VNA의 female 포트에 직접 꽂는 대안은 케이블 제거·새 기준면 검토가 필요하므로 기본 연결표와 섞지 않는다.
- **스코프로 이동:** SMA 기준면 교정에 ADAPT가 포함됐다면 제거 후 기존 ZT를 재사용하지 않는다. [전체 연결표와 BNC 기준면 경로](END_TO_END_REHEARSAL.md) 2~3절을 따른다. 901-9173의 [제조사 규격](https://www.amphenolrf.com/en-us/part/901-9173/7570/)은 성별·50 Ω·4 GHz 확인 근거이며 개체 교정 데이터가 아니다.
- 감쇠기/SMA 플러그를 헤드에 직접 체결할 공간은 미확인이다. 낮게 내려오는 큰 몸통과 덮개 간섭 가능성이 있다. 실제 체결 깊이를 확인하고 필요한 경우 별도 짧은 SMA 케이블을 추가하되 수량/비용/체인 ID/교정을 함께 갱신한다.

참고: [Tektronix의 SMA 출력–TekVPI BNC 입력 연결 안내](https://www.tek.com/ja/support/faqs/how-do-i-connect-sma-male-output-oscilloscopes-tekvpi-bnc-inputs). 이 자료는 접속 방식의 근거이며 CAB-01의 제품별 주파수 사양·길이·가격을 검증한 자료는 아니다.
