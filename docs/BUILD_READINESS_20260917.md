## 4. PCB 제작 조건 검토

초기 견적 조건은 **FR-4, 2층, 완성 1.6 mm, 외층 1 oz, 무연 HASL, 녹색 마스크, 흰 실크, 20×16 mm 라우팅, 손납땜, 비제어 임피던스**다. 첫 헤드는 1개 사용, 견적 수량은 5개로 시작한다. 실제 최소 주문 수량/가격은 확인 전이다.

[JLCPCB 공개 제작 능력](https://jlcpcb.com/capabilities/Capab)을 2026-09-17 확인했다. 공칭 1.6 mm의 ±10% 범위는 1.44~1.76 mm, 일반 라우팅 ±0.2 mm, through-hole 지름 +0.13/−0.08 mm, 홀 위치 ±0.05 mm다. 실크 높이 1.0 mm/획 0.15 mm에 맞춰 A0.2를 수정했다. 작은 bare PCB 최소 크기와 PCBA 조립 최소 크기를 혼용하지 않았다.

**남은 차이:** GCT 권장 PCB 도면은 ±0.05 mm를 표기한다. 제작사의 일반 홀 지름 공차를 그 요구에 적합하다고 간주할 수 없다. Ø1.50/Ø1.70 완성 홀과 핀 공차를 제작사/실물로 대조해야 한다. 프레스핏 특수 공차 옵션은 현재 2층 HASL 안에 자동 적용되지 않는다. 보드 ±두께·외곽 공차와 프린터 오차를 합친 기구 맞춤도 미검증이다. 짧은 신호 배선을 50 Ω 제어 임피던스선이라고 표시하지 않는다.
