## 1. 선정 결과

**현행 구경 결정(2026-09-22):** 사용자는 실제 대상의 큰 지름이 약20 mm 수준이며 현행26 mm 기준이면 충분하다고 확인했다. A14 헤드의 고정바를 포함한 공칭 통과 지름은 약26.40 mm이고 C07의 공칭 작동 범위는6–26 mm다. 따라서 아래 초기30 mm 목표는 현행26 mm 기준으로 대체한다. 실제 최대 구경 보증과 혼동하지 않는다. [독립 재검토](../reviews/independent_release_review_20260922/README.md).

**초기 선정 이력:** 1차 시제품은 Fair-Rite 2644181281, 44 재료의 분할 코어로 진행한다. 두 반쪽으로 자기 경로를 닫는 구성, 고정 반쪽의5턴 권선, 유효 구경30 mm 목표, 비도전성 힌지 하우징과 캠 잠금을 설계 시작안으로 선택했다. DEC-011에 기록한 당시 시작안이며 잠금 기구도 이후 A14로 변경되었다.

이것은 부품·실험 순서의 선정이다. 실측 대역·감도·반복성의 확정이나 구매 실행을 의미하지 않는다. 사용자에게 재료나 턴 수를 다시 선택하도록 묻지 않는다. 실제 케이블/다발과 주변 공간은 기구 제작 전에 대조한다.

선정 이유는 넉넉한 내부 공간, 짧은 축방향 길이, 조달 가능한 표준 부품, 첫 코어 비용을 낮춰 교정·보호 예산을 남길 수 있다는 점이다. 짧은 코어가 반드시 더 넓은 RF 대역을 보장한다는 뜻은 아니다.

### 대역 목표 확인 — DEC-012

**1~100 MHz는 첫 검증 구간이며 최종 상한이 아니다.** 백서의 전체 개발 목표 100 kHz~300 MHz와 500 MHz 특성 확인·확장 목표를 유지한다. 사용자가 200 MHz 이상 관측 필요성을 제기했으므로, 후속 비교에서는 100~200 MHz와 200~300 MHz의 연속 응답·잡음·직접 픽업·지그 유효성을 명시적으로 평가한다. 몇 개 주파수 점만 통과했다고 연속 대역이 확보되었다고 판단하지 않는다. 100 MHz 검증만으로 개발 목표 달성을 선언하지 않는다.

100 Mbps는 데이터율이고 MHz는 주파수이므로 `100 Mbps×2 = 필요한 프로브 대역 200 MHz`로 환산할 수 없다. 일반 100BASE-TX는 별도의 선로 부호화를 사용한다([Microchip AN1120](https://ww1.microchip.com/downloads/en/appnotes/01120a.pdf)). 본 프로브의 대상은 케이블의 RF 합전류이며, 데이터율만으로 공통모드 잡음의 상한을 정하지 않는다. 산업용 Ethernet에는 전원·접지·인접 신호·클록 고조파의 결합도 검토해야 한다([TI SNLA466A](https://edgeworker.ti.com/lit/pdf/snla466)). 두 자료 조회일은 2026-09-15다.

현재 코어·5턴 선정은 실험 시작안이다. 200/300 MHz에서 유효한 ZT와 측정 체인을 아직 입증하지 않았으며, 상위 대역의 실패 시 리드·권선·차폐·지그 또는 코어를 재검토한다. 부품의 억제 주파수 사양으로 이 검증을 대신하지 않는다.

### 출처 간 차이와 남은 확인

- 선정품 제조사 설명은 `44 ROUND SPLIT CABLE CORE`다. 일부 DigiKey 페이지의 `Solid` 분류와 충돌하므로 제조사 설명을 우선한다. 구매 시 같은 부품번호의 반쪽 단위와 실제 포장 구성을 확인한다.

## 3. 구경과 잠금 구조

### 구경

첫 기구 목표는 **완성 후 유효 구경 30 mm**다. 백서의 30~35 mm 탐색 범위 중 하단을 우선한다. 선정품의 제조사 케이블 지름 안내 33 mm를 기준으로 권선·절연·보호 라이너가 각 측면에서 1.5 mm 이내를 차지하도록 배치하는 치수 예산이다.

`CALCULATED: 33 − 2×1.5 = 30 mm`.

이 식은 제조 공차까지 검증한 최소 구경 보증이 아니다. 도면·실물 형상과 권선 돌출을 확인한 뒤 가장 좁은 방향을 검사한다. 열린 진입 폭도 30 mm 이상을 기구 목표로 둔다. 최종 판단에는 실제 케이블/다발, M12 너트·RJ45 부트/래치 등 인접 간섭을 포함한다.

### 채택할 기구 방식 — 설계안

1. 코어 두 반쪽을 별도의 비도전성 하우징에 담는다. 고정 반쪽에 권선·헤드 PCB·SMA를 모으고, 가동 반쪽에는 전기 배선을 통과시키지 않는다.
2. 한쪽 외곽에 힌지, 반대쪽 외곽에 손으로 여닫는 오버센터 캠 잠금을 둔다. 힌지는 외측 M3급 나일론 축을 시작안으로 한다. 축·캠의 최종 치수는 도면 확인 후 설계한다.
3. 하우징은 PETG 기구 시제품을 시작안으로 한다. 재료·적층방향·벽 두께·온도·크리프 내구성은 검증 전이다. 절연 안전 정격을 부여하지 않는다.
4. 정렬 턱으로 두 반쪽의 가로 이동을 막고, 코어 뒷면의 탄성 패드로 접촉 압력을 준다. 캠 닫힘 위치와 과압축 방지 스토퍼를 두되, 스토퍼가 너무 일찍 닿아 코어 접합면에 틈을 남기지 않게 조정한다.
5. 접합면 사이에는 테이프·접착제·패드를 넣지 않는다. 페라이트를 절단·연마해서 맞추는 계획도 사용하지 않는다. 접합면 오염·파손과 권선 끼임을 점검할 수 있어야 한다.
6. PCB·차폐·SMA 외피·나사 경로가 코어 구멍을 통과해 밖으로 돌아오는 단락 턴을 만들지 않도록 별도 3차원 검토한다. 비도전성 하우징만으로 RF 차폐가 완료되지는 않는다.

잠금 힘은 임의 숫자로 확정하지 않는다. 같은 잠금 위치로 접합면이 재현되는지를 먼저 확인하고, 개폐 내구성과 T05 반복성으로 고정한다. 이 하우징은 도면·CAD·실물이 아직 없는 기구 아키텍처 선정이다.

## 4. 권선 시작안과 비교 계산

- 시작: **5턴**, 고정 반쪽에 단층으로 분산 배치한다. 도체를 코어 창으로 통과시켜 해당 반쪽 바깥으로 되돌리는 한 바퀴를 1턴으로 센다. 두 접합면은 비워 둔다.
- 도선 시작안: 도체 지름 약 0.3 mm의 절연 에나멜선. 실제 피복 외경·온도 등급·코어와의 추가 절연은 구매 품목 선정 시 확인한다. 권선 아래 얇은 절연층을 두되 접합면은 덮지 않는다.
- 두 출력 리드는 함께 짧게 헤드 PCB로 보낸다. 각각 5 mm 이하를 배치 목표로 두며 실제 길이를 기록한다. 수신기 쪽 단일 50 Ω 종단을 유지한다.
- 시험 순서는 같은 코어·하우징에서 **5 → 3 → 7턴**이다. 코어와 턴 수를 동시에 바꾸지 않는다. 다시 감을 수 있도록 초기에는 영구 포팅하지 않는다.
- 반쪽에 집중된 권선은 위치 민감도와 직접 픽업을 확인해야 한다. 분포 권선이나 가동부 배선 추가는 T06/T08 결과가 필요할 때만 검토한다.

## 6. 선정 이후의 실행 순서

1. 선정품의 실제 도면/STEP과 판매 단위 확보 → 두 반쪽·권선·하우징 간섭과 30 mm 구경 확인. 그림 열람 실패를 사용자 취향 질문으로 바꾸지 않고 다음 자료 접근에서 해결한다.
2. 기구 초안과 지그 중심 도체/외부 귀환 경로 작성 → 헤드 PCB 배치·차폐·보호 체인·전체 실견적 정리.
3. 제작 조건을 충족한 후 5턴 시제품으로 T01, 저전력 지그 특성화 및 T02~T04, T05/T06/T08/T10 순으로 검토. 측정 전 실제 장비 설정과 보호를 확정한다.
4. T05는 최소 5회 개폐·재장착하고 접합면·잠금 위치를 기록한다. 3/7턴은 동일 지그에서 다시 비교하며 매 변경에 구성 ID와 새 교정 ID를 부여한다.

실제 수행: 세 후보 제조사 자료·조달 표시값 비교, 모델 산술 실행, 설계 시작안·비용 배정 선정. 미실행: 도면 이미지 검사, CAD, 실제 권선/잠금 시험, 복소 투자율 RF 시뮬레이션, 지그 검증, 실측 교정, 보호 정격 검증, 구매. **G1 전체는 아직 완료하지 않았다.**
