# 교정지그 전류 경로와 모델 검토

> **현행 기준 안내 · 2026-09-21:** 기구·구매 수량·발주 상태는 [CURRENT_READINESS.md](CURRENT_READINESS.md)와 [최종3D 제작 기준](3D_PRINT_RELEASE_A16_C09.md)을 따른다. 아래는 해당 작성일의 기록이다. 교정 수식·기준면·종단·보호 원칙은 계속 적용하지만, 옛 동판/패드·구매 수량·제작 완료 표현은 현재 지시가 아니다.

## 1. 첫 실험 구조

지그는 양끝 SMA와 교체 가능한 중심 도체, 코어 바깥의 귀환 프레임으로 구성한다. 첫 지그는 구조를 바꿀 수 있게 만들고 through 측정으로 유효 대역을 정한다. 50 Ω 종단을 붙였다는 이유만으로 전체 지그를 50 Ω 전송선으로 취급하지 않는다.

```text
P1 중심 ── 중심 도체 ── [코어 구멍 안] ── F-A.OUT 중심 ── 50 Ω 일차 부하
P1 외피 ←── 코어 외곽보다 바깥에 있는 귀환 프레임 ←── F-A.OUT 외피

                         코어의 5턴 권선
                              │
                      헤드 SMA ── 출력 체인 ── P2 (50 Ω)
```

일차 부하와 P2의 50 Ω는 서로 다른 회로의 종단이다. 헤드 권선에 별도 50 Ω를 병렬로 추가하지 않는다. 중심 도체와 아래쪽 GND를 함께 구멍에 넣지 않는다. 출력 동축도 구멍으로 돌아가지 않게 고정한다.

### F-A 가변 구조의 시작 치수 — 설계 가정

| 항목 | 시작안 | 확인 방법 |
|---|---|---|
| 중심 도체 | 두께 0.5 mm, 폭 8 mm 동 스트립; 모서리 처리 | 치수 기록, 도체 교체 전후 T02/T03 |
| 중심 구간 길이 | 약 60 mm, 코어 중심에서 양쪽 SMA까지 약 30 mm | 실제 SMA 런치 포함 길이 측정 |
| 외부 귀환 | 중심축에서 좌우 약 55 mm에 폭 10 mm 동 스트립 두 개 | 하우징·힌지 간섭, 두 귀환 모두 코어 밖인지 사진 |
| 양끝 연결판 | 중심 핀 절연, SMA 외피와 귀환 프레임 연결 | 중심-귀환 단락 검사; 연속 GND판이 구멍을 관통하지 않음 |
| 코어 지지 | 비도전성 위치 스토퍼; 중심/치우침 위치 표식 | T05/T06 반복성 |
| F-A.OUT | through 때 P2 케이블, 프로브 교정 때 RF 50 Ω 부하 | 동일 기준면, 부하 S11, 부하 식별자 |

이 치수는 제작 확정치가 아니다. 넓은 귀환 간격과 얇은 중심 도체는 높은 선로 임피던스·전이를 만들 수 있다. 먼저 T02를 수행하고 중심부 폭/길이·귀환 형상을 조정한다. 실패한 대역을 숫자 보정만으로 통과시키지 않는다.

## 2. 연결 모드

| 모드 / 저장 파일 | 연결 | 확인 목적 |
|---|---|---|
| `fixture_through_empty.s2p` | P1 → F-A → P2, 프로브 없음 | 지그 자체 정합·손실·공진 |
| `fixture_through_head_loaded.s2p` | 같은 through, 헤드는 단일 50 Ω 부하로 종단 | 헤드 삽입으로 바뀌는 일차 경로 |
| `probe_transfer_5t_Lxx.s2p` | P1 → F-A → F-A.OUT의 50 Ω; 헤드 → P2 | S11/S21와 출력 체인 |
| `leakage_control.s2p` | 같은 배선에서 권선 대신 작은 비유도 50 Ω 더미, 위치 기록 | 직접 결합의 실험적 상한 검토; 완전 등가 대조라고 가정하지 않음 |
| `cancellation_control.s2p` | 별도 대조에서 일차 귀환도 코어 안으로 통과 | 상쇄 확인; 바뀐 일차 전류로 정규화 필요 |

through 측정과 프로브 출력 측정은 P2의 접속 위치가 다르므로 서로 다른 measurement/setup ID와 원시 파일로 기록한다. 지그 정합만 좋고 코어 위치 전류 모델이 없으면 절대 교정이 아니라 **지그 고정 상대 특성화**다.

후속 구분: 같은 테스트 케이블 끝이라는 기준면/구성이 유지되면 유효한 SOLT 교정 ID는 공유할 수 있다. 접속 대상별 측정 파일·setup ID를 분리한다. 어댑터를 추가/제거한 경우에는 별도 기준면 검토가 필요하다. 구체적인 [부하 이동과 연결표](END_TO_END_REHEARSAL.md)를 따른다.

### 집게와 함께 조립할 때 — 후속 CAD 검토

지그 좌표는 케이블 축 Z, 코어 중심 Z=6.35 mm다. 중심 스트립은 X 폭 8 mm/Y 두께 0.5 mm, Z=-23.65~36.35 mm로 해석했다. 두 귀환은 X=-60~-50 mm 및 50~60 mm에 놓았다. [저장 CAD와의 검사](../mechanical/clamp_A01_DRAFT/connection_access_review.json)에서 닫힘과 0~90° 개방 샘플은 간섭이 없으나 110°부터 가동부와 귀환이 충돌했다.

**F-A 안에서는 개방을 90° 이하로 제한하고 비도전성 스토퍼/지지대를 마련한다.** 집게 단독 120° 검사 결과를 전용하지 않는다. 이번 검사는 동 스트립만 포함한다. SMA 런치·양끝 연결판·지지대의 실제 형상과 스트립 조립/진입 경로는 추가 검토해야 한다. 스트립 표면과 측정 도체의 절연 조건도 확인한다.

## 3. 코드로 구현한 세 전류 모델

실수 기준 임피던스 `Z0=50 Ω`, 정합된 P2에 대해 `V2=√Z0·b2`, `S21=b2/a1`을 쓴다. `a1`의 단위는 √W이며 `HI=Icore/a1`의 단위는 A/√W다.

| 모드 | 식 | 추가 조건 |
|---|---|---|
| `relative` (기본) | S21만 출력; ZT 비움 | 전류 모델 미검증 상태 |
| `matched` | `ZT=50 S21` | 코어까지의 전류 기준·정합 경로 확인; 위상은 별도 증거 |
| `input_current` | `ZT=50 S21/(1−S11)` | 입력 기준면의 전류와 코어 전류가 같고 우회 분기·미처리 지연이 없음 |
| `hi_model` | `ZT=√50 S21/HI` | 동일 주파수 격자의 복소 HI와 모델/기준면 증거 |

단위 검산: `(√Ω × 무차원)/(A/√W)=Ω`. 정합 시 `HI=1/√50`이므로 일반식은 `50 S21`로 환원된다. −20 dB S21 → 5 Ω → 13.979400 dBΩ. 전력식은 `Pout−Pin+33.979400`, DEC-008의 부호를 유지한다.

## 4. 우회 전류가 있는 합성 반례

[fixture_model.py](../analysis/fixture_model.py)는 입력 기준면의 병렬 C가 코어를 통과하는 직렬 L+R 분기를 우회하는 회로를 계산한다.

```text
입력 노드 ── L ── 코어 전류가 흐르는 R 분기 ── 귀환
    └──────────────── C ───────────────── 귀환
```

`Ybranch=1/(R+jωL)`, `Zin=1/(Ybranch+jωC)`, `S11=(Zin−50)/(Zin+50)`, `HI=√50(1+S11)Ybranch`다. 검산용 가정값은 L=30 nH, C=3 pF, R=52 Ω, 참 ZT=5 Ω다. **실제 지그 추정값·EM 시뮬레이션·실측이 아니다.** S12/S22는 분석에서 사용하지 않는 0 자리표시이며 물리적인 전체 2포트 모델을 주장하지 않는다.

합성 계산에서 약 300 MHz의 입력 S11을 무조건 `1−S11` 보정하면 크기는 약 +2.60 dB, 위상은 약 −23.37° 어긋난다. 알려진 HI를 쓰면 5 Ω가 복원된다. 반대로 이상적인 정합 선로도 지연이 있으면 S11=0인 채 위상 기준은 달라진다. 따라서 S11 하나로 위상·전류 경로를 입증할 수 없다.

원본 합성 데이터·가정·수치는 [tests/synthetic](../tests/synthetic/bypass_fixture.json), 자동시험은 [test_rfcp.py](../tests/test_rfcp.py)에 있다. 이 반례의 오차를 실제 프로브의 오차로 적용하지 않는다.
