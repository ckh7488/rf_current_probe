# 현행 설치 BOM 및 통합 구매 기준

2026-09-29 독립 재검토 반영(DEC-079). **현행: Head A04 SMA R2 / Fixture A03 SMA R2 / VNA B-RJ2 / A18·C10.** 실제 원본과 제조 ZIP은 [현재 제작 구성](CURRENT_BUILD.md), 업체 심사·결제 상태는 [STATUS](STATUS.md)를 따른다. DRAFT 표시는 최종 제조파일·생산승인 전이라는 의미로 유지한다.

이 표는 프로브·교정지그의 설치 위치 57행이다. 삭제된 체결품 4행은 ID 추적을 위해 설치0으로 남긴다. 설치량·보유품·구매 포장·예비품을 혼동하지 않는다. **VNA까지 포함한 실제 구매 지시는 [구매팀 HTML 31행](../outputs/purchasing-handoff-20260929/구매안내_20260929.html)**이다. 9/28 구매검수는 이력이며 현행 지시를 대체하지 않는다. [이번 독립 검토](../reviews/independent_current_audit_20260929/REPORT.md)와 [수정 전 원문](../reviews/independent_current_audit_20260929/before/docs/BOM_DRAFT.md)을 보존했다.

## 측정·준비물

LibreVNA·오실로스코프·SOL·인두 보유 기록과 실제 교정·작동 완료는 다르다. THRU 성별/모델, DUT면 교정 표준, 패치선, 실납·테스터·치수/체결 공구는 [현행 조립 전 준비표](../outputs/purchasing-handoff-20260929/조립전_준비확인_20260929.md)로 확인한다. **LLC용 수 M12 1개는 사용자 보유 확정·신규구매0이며, 별도 M12 지지 패널/브래킷을 필수품으로 요구하지 않는다.**

DEC-055의 대상 하네스는 맨 프로브가 기본이며 새 현장·새 케이블 첫 확인은10dB 감쇠기로 시작한다. D01–D03은 기존 진단 어댑터·접지면·기준선 활용 계획, D04 스냅온 페라이트는 선택 구매, D05 굴곡은 절차 항목이다. 발룬 CT의0Ω은 기본 미실장이며 PWR/GND 쌍 CT를 단락한 보드의 통전을 금지한다. 과거 보유 기록은 이번 신규 VNA 보드가 이미 실장·검증됐다는 뜻이 아니다.

실물 조립, RF 응답·삽입 영향·재현성 및 T01–T12 측정은 미실행이다. [입고·벤치 확인](../reviews/full_reinspection_20260928/ACCEPTANCE_PLAN.md)과 백서11.6/14.5의 조건을 따른다. 공개 페이지의 옛 조립 BOM은 최신 구매 지시를 대신하지 않는다.
