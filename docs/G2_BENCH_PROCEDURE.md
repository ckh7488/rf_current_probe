## 1. 처음 할 실험

첫 실험은 **수동 지그에 LibreVNA 자체의 낮은 레벨 신호만 공급**한다. 산업용 케이블에는 아직 연결하지 않는다. 외부 전원/펄스가 없는 수동 구성의 정격·결선을 확인한 뒤 시작한다. 대상 하네스는 맨 프로브가 기본이며, 새 현장·새 케이블의 첫 측정은 R05 10 dB 감쇠기로 최대값을 먼저 확인한다(강력 권고, DEC-055).

준비물: 실제 코어 두 반쪽, 권선/절연, 분리 가능한 지지대, SMA 출력, 실제 사용할 교정지그, 확인된 SMA 수 RF 50 Ω 부하 최소1개(일차/헤드 종단 위치를 RF OFF 후 이동),50 Ω 동축2개, 해당 기준면에서 쓸 수 있는 교정키트. [시제품 BOM](BOM_DRAFT.md)의 보유 여부와 대조한다. 교정지그는 Fixture A03다. J1/J2 방향을 기록하고, 역방향 반복 때 바꾼 방향도 기록한다. 절대 교정식은 백서 11.6의 출력 포트 기준이며 입력 진행파 기준 `50×S21`을 자동 적용하지 않는다. Through는 P2가 지그 출력을 종단하고 외장 로드는 헤드에, Transfer는 외장 로드를 지그 출력으로 옮기고 P2를 헤드에 연결한다. 수신기 단일50 Ω를 유지한다.

실물에서 처음 기록할 값은 코어/케이블 치수, 코어 접합면 상태, 도선 피복 외경, 장비 HW/FW/GUI 버전, 교정키트/동축/부하 ID다. 사용자에게 재료 선택을 넘기기 위한 질문 목록이 아니라 실험 기록 항목이다.

## 2. 조립 및 T01

[현행 원본·조립 순서](G3_PROTOTYPE_PACKAGE.md)와46단계 절차를 따른다. 사용자 재단 패드/별도 스프링은 없다. 출력물·홀 맞춤은 입고 후 확인한다. 아래 F-A는 측정 연결도의 일반 지그 별칭이며 특정 제작 리비전을 승인하는 이름이 아니다.

1. 코어의 두 접합면을 깨끗하게 맞춘다. 연마면을 사포로 가공하거나 사이에 테이프를 넣지 않는다.
2. 고정 반쪽의 권선 위치에 추가 절연을 두고 연속 5턴을 감는다. 가동 반쪽에는 배선을 연결하지 않는다. 권선 시작/끝과 정방향을 사진으로 남긴다.
3. SMA만 먼저 PCB에 납땜한다. 권선 끝선은 분리해 두고 H05 경로로 PCB를 장착한 뒤 M2×12 두 개로 고정한다. 그다음 두 리드를 짧게 S+/S−에 납땜하고 아래 고정바를 단다. 헤드의 병렬50 Ω 저항은 없다. PCB 탈착 전에는 권선 납땜을 제거한다.
4. SMA 중심-외피 사이에는 **권선의 낮은 DC 저항**이 보이는 것이 정상이다. 이 측정으로 헤드 출력을 단락 불량이라고 판단하지 않는다. 대신 권선 단선, 권선/차폐와 일차 도체 사이의 의도하지 않은 도통을 검사한다.
5. 지그의 일차 50 Ω 부하를 제거했을 때 중심-외피가 단락되지 않아야 한다. 부하를 끼웠을 때는 대략 해당 부하 저항을 확인한다. 이것은 RF 정합·내전압 시험을 대신하지 않는다.
6. 전체 귀환과 출력 동축, 하우징 금속이 코어 구멍을 다시 통과하지 않는지 확인한다. 사진과 DMM 결과를 저장한다.

## 3. LibreVNA 설정과 기준면

공식 매뉴얼의 VNA mode, Level/Points/IF BW/Averaging, full two-port calibration, trace export를 따른다. 실제 버전에서 지원되는 값을 장비 화면에서 확인하고 저장한다. 아래 수치는 **실험 시작 설정안**이며 실행한 설정이 아니다.

| 구간 | 시작/끝 | 포인트 | 목적 |
|---|---|---:|---|
| B — 먼저 실행 | 1~100 MHz | 1601, linear | 초기 실용 구간 |
| A | 100 kHz~10 MHz | 1601, linear | 저주파 감도·roll-off |
| C | 100~300 MHz | 1601, linear | 100~200 / 200~300을 별도 판정 |
| D | 300~500 MHz | 801, linear | 같은 A03의 출력 포트 기준 보정·오차 평가 |

- 초기 소스 레벨 −30 dBm, IF BW 1 kHz, averaging 4 sweeps를 제안한다. 지원되지 않으면 가능한 값을 기록하며 조정한다. 좁은 피크/null은 해당 구간의 포인트를 늘린다.
- T04에서는 −30/−20/−10 dBm 세 레벨을 제안한다. 장비 입력 정격과 실제 선형 범위를 우선한다. 이 값을 외부 신호의 허용치로 해석하지 않는다.
- 케이블 끝에 올바른 표준을 연결해 전체 2포트 교정을 한다. 포트별 기준면·주파수·레벨·교정키트 모델을 저장한다. 레벨/구간 변경 시 교정의 유효성을 확인하고 필요하면 다시 교정한다.
- P2 테스트 케이블 끝이 F-A.OUT에서 HEAD.OUT으로 이동해도 같은 기준면/케이블과 유효 교정이 유지되면 기존 SOLT를 사용할 수 있다. 접속 대상별 measurement/setup ID와 재접속 검증은 따로 기록한다. 케이블/어댑터를 추가·제거한 경우와 혼동하지 않는다.
- GUI math, smoothing, port extension, de-embedding은 사용 여부/설정과 순서를 모두 기록한다. 첫 기록은 임의 후처리 없이 교정된 네 S-parameter를 저장한다. 기준면 처리된 파일만 남기고 원시 내보내기를 삭제하지 않는다.
- 각 레벨 변경 후 평균이 충분히 갱신된 완전한 sweep을 저장한다. 서로 다른 시점에 pause된 S11/S21을 합치지 않는다.

T04의 +10 dB 검산은 S21에 소스 레벨을 다시 결합해 수신 레벨을 비교하거나 실제 수신 레벨 로그로 수행한다. 선형 DUT의 S21이 10 dB 증가해야 한다는 잘못된 판정을 하지 않는다.

## 5. 오실로스코프 단계 — T09/T11 후속

실물 MSO4054 명판과 입력 상태를 확인하고, 제조사 예열/SPC 조건 및 검증된 체인을 적용한다. 기본 연결은 `헤드 SMA → R06 SMA–BNC → CH1 내부 50 Ω`이며, 새 현장·새 케이블의 첫 측정·착탈·전원 투입 때는 헤드 SMA 뒤에 R05 10 dB를 넣는다(강력 권고). VNA 교정은 스코프 내부 주파수 응답을 보정하지 않는다.

VNA 파형을 저장한 후 RF OFF에서 재배선하고 **CW mode/P1만 출력**으로 바꾼다. 소스 레벨·주파수를 다시 확인한다. LibreVNA의 고조파/레벨 오차 때문에 전체 RMS나 명목 dBm으로 절대 전류를 검증하지 않는다. 먼저 1/10 MHz의 **기본파 성분**과 소스 OFF 잡음/레벨 변화부터 확인한다.

설정은 **DC coupling, 내부 50 Ω, Voltage probe 1×, FULL, Sample**로 시작한다. 원 MSO4054는 AC coupling이면 1 MΩ로 바뀐다. 외부 감쇠 보정을 스코프 배율에 중복 적용하지 않는다. 원 MSO4054는 수직 감도에 따라 대역이 달라지므로 1~1.99 mV/div에서 300 MHz가 보장되지 않는다([장비 기준표](INSTRUMENT_BASELINE.md)). FFT·스펙트럼은 표시 샘플레이트 1 GS/s 이상에서 보고, 저역을 길게 잡을 때는 대역 제한(20 MHz) 또는 Hi-Res를 켜서 접힘을 막는다.

스코프 체인(R06+CH1)의 주파수 응답은 LibreVNA CW 출력으로 확인한다([전체 절차 3.2절](END_TO_END_REHEARSAL.md)). BNC 어댑터(R07)는 쓰지 않는다. 확인 전에는 V 단위 관측으로 둔다. [전체 절차 3~5절](END_TO_END_REHEARSAL.md)에 실제 교정 경로, 원시 CSV 보존/정규화, 기본파 분석 및 A 환산 조건을 지정했다. 낮은 에너지 수동 CW 벤치는 T11의 현장 펄스 보호 시험과 별개로 진행할 수 있지만, 실제 정격·결선 확인은 필요하다.

스코프 검증 전에는 펄스 최대값을 하나의 ZT 숫자로 나누지 않는다. 제한된 펄스 시험은 펄스원·종단·최대 에너지·실제 보호 부품 정격을 정한 뒤 별도 시행한다. raw waveform, sample rate, record length, volts/div, coupling, bandwidth, trigger, clipping flag를 저장한다. 검증되지 않은 위상으로 시간 파형을 복원하는 기능은 현재 코드에 없다.

[metadata_template.json](../analysis/metadata_template.json)을 복사해 실제 관측값으로 채운다. 이 양식 자체는 측정 데이터가 아니다. `clipped=null`은 의도적으로 분석을 거부한다. 관측 후 true/false를 명시한다. 평가 전에는 `current_model.mode=relative`, `valid_frequency_bands_hz=[]`, `uncertainty_db=null`, `phase_validated=false`를 유지한다.

현장 추가 기록: 통과시킨 도체군·쉴드 포함 여부, DUT 상태/회전 위치, 주변 장비 상태, 장애 로그와 파형의 시간 동기 관계, clipping/overload. T12로 현장 전후 동일 지그 응답을 비교한다. 현장 적용은 보호·장착 검토가 끝난 뒤 사용자 승인 범위에서 수행한다.

## 7. 다음 판단

첫 데이터는 **T02 through, 5턴 전달 S21, 로드 S11, 역방향 반복**이다. 이것으로 출력 기준 ZT와 K의 실물 일치를 보고, 5턴을 유지할지 필요한 대역 때문에 3턴을 추가로 감을지 결정한다. 출력 기준 계산은 `analysis/rfcp.py`의 `output_reference`를 사용한다. 정·역방향 원본과 로드 S1P, 복소 K, 실제 검토한 주파수별 불확도·품질을 묶어 입력한다. 조건이 없는 구간은 절대 ZT를 표시하지 않는다. 1–150 MHz 판정용 재현성을 먼저 확인하고 같은 A03으로1–500 MHz 보정을 수행한다. 주파수별 ZT·불확도·유효성을 남기며300 MHz에서 일괄 제한하지 않는다. 실험 전에는 어느 대역도 확보됐다고 보고하지 않는다.

출처: [LibreVNA 공식 매뉴얼](https://github.com/jankae/LibreVNA/blob/master/Documentation/UserManual/manual.tex), [Tektronix 원 MSO4054 검증 매뉴얼](https://download.tek.com/manual/077024701Rev_A_web.pdf), [프로젝트 백서](RF_CURRENT_PROBE_WHITEPAPER.md). 조회 2026-09-15~16. 장비 설정안·지그 치수는 이 프로젝트의 제안값이다.

## 8. 실물 도착 후 작성할 시험 문서 (DEC-055)

아래는 이 초안에 세부를 넣지 않고, 실물로 한 번 해 본 뒤 시험별 문서로 만든다.

- 권선 자기공진 S11(위 순서0)과 턴수 판단.
- 불량 샘플 대조: 정상 상용 케이블이 합격하고, 불량 모사 어댑터(예: 한 가닥에만 22 pF)를 끼운 상태가 불합격하는지 먼저 확인한 뒤 대상 케이블을 잰다.
- 지그 체인 누화 바닥: 케이블 없이 M12→RJ45 어댑터 + 발룬 보드의 쌍간 S21. 판정하려는 NEXT 한계보다 10 dB 이상 낮아야 그 대역 NEXT 판정에 쓴다.
- 발룬 보드 두 벌 운용: 센터탭 띄움(DM 측정·통전 가능) / 0 Ω 여덟 개 실장(불균형 측정·**통전 금지**). 발룬 DM 입력 + RF 프로브로 DM→CM 불균형을 본다.
- 간헐 단선 굴곡 시험: 1 kΩ·5 V USB 전원·점퍼, 오실로스코프 트리거.
- 결과는 백서14.5 표로 판정용/참고용을 표시하고, 측정마다 사용한 기준 케이블과 배치를 기록한다.
- 현장 진단 A/B: 필요하면 D04 스냅온 페라이트를 끼우기 전후의 CM 전류와 링크 오류를 비교한다.
