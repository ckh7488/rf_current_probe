## 사용자에게 보여주는 네 장면

1. **구조·개폐:** 실제 A05 CAD를 회전/확대하고 개폐 슬라이더 또는 재생 버튼으로 확인한다. 두 M4 손나사를 제거한 뒤 상부가 직선으로 분리된다. 하우징 투명 표시로 코어 받침과 스프링 외형을 볼 수 있다.
2. **실험실 교정:** Port 1→큰 PCB 입력, 반대 SMA→50 Ω 로드, 헤드 SMA→Port 2. 지그 통과 특성 측정이나 VNA 자체 교정 단계와 구분한다.
3. **지그에서 분리:** 상부 제거·별도 보관→큰 PCB 제거→M2 너트 해제→작은 PCB와 하부를 함께 분리→M2×10 독립 고정.
4. **케이블 측정:** 대상 케이블을 감싼 헤드와 출력 동축만 표시한다. 큰 교정 PCB·기둥·베이스는 실험실에 남긴다. 작은 헤드 PCB는 계속 장착한다.

## 중요한 사용성 결론

의도한 현장 구성은 **프로브 헤드+동축+검증된 보호·감쇠/50 Ω 수신 체인+계측기**다. 지그를 통째로 가지고 다니거나 큰 PCB만 빼고 지그에 얹힌 채 사용하는 구성이 기본은 아니다. 프로브 자체는 배터리·화면·기록 기능이 없는 수동 센서다. 현장에 운반한 뒤 케이블 가까이 지지해 사용하는 방식이다.

현재 A05는 노출된 권선/PCB와 분리형 상부/손나사가 있고, 브래킷과 작은 PCB가 나사 두 개를 공유한다. 실험실↔현장 전환이 잦으면 독립 탈착 브래킷, 부품 분실 방지, 외부 보호, 동축 하중 지지 개선이 필요하다. 이것을 이미 완성된 휴대용 구조라고 표시하지 않았다.

## 실제 확인과 미확인

- 저장 CAD 메시 45개 구성품/477,184 삼각형을 단순화 없이 포함. float32 좌표 변환 최대 오차 0.000003814 mm. 외부 케이블·로드·연결 라벨·화살표만 설명용이다.
- 기존 A05 경로 검사에 더해, 큰 PCB·상부·M2 너트를 제거한 뒤 하부/작은 PCB를 +Z로 0–60 mm 이동하는 31개 위치를 FreeCAD 1.0.2로 검사했다. 공칭 겹침 0. `viewer_A05/detachment_check.json`.
- Node 검사에서 현장 장면의 지그 제외/작은 PCB 유지, M2 교체, 닫힘·열림 끝점, 스프링 양끝과 3.95 mm 따라 움직임을 확인했다.
- 브라우저에서 네 장면, 개폐 80 mm 끝점, 76.05 mm 받침 이동, 재생 버튼, 교정/현장 연결, 분리 장면을 확인했다. 조회된 경고/오류 로그 없음.
- 직접 `file://` 실행 검사는 브라우저 도구의 URL 보안 정책에 의해 차단되어 수행하지 않았다. 우회하지 않았다. 단일 HTML의 외부 참조 없음은 정적 검사, 실제 동작은 HTTP 브라우저 확인에 근거한다. 모바일 실기기 시험은 하지 않았다.
- **실물 조립·마찰·힘·공차·RF 특성과 현장 보호 체인은 미검증.** 이번 뷰어 배포는 제조 승인이나 계측 사양 달성 선언이 아니다.
