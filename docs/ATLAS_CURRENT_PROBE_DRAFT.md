# ATLAS RFCP 현행 문서

2026-09-22 · [공개 페이지](https://ckh7488.github.io/showcase/reports/rf-current-probe/)

이 문서의 공개 설명 기준은 Head A04 / A14·C07, 출력15종20개와 당시45단계 조립절차·57행 BOM이다. 최종3D 제조 선택은 [A16/C09 확정 기준](3D_PRINT_RELEASE_A16_C09.md)을 따른다. E03 교정지그는 Fixture A03(출력 포트 기준 교정, DEC-053)이며1–500 MHz 보정을 수행한다. 실제 CAD와 원자료를 연결하되 계산/시뮬레이션과 실측 사양을 구분한다. 이전 A0.2/8단계 자료와 별도 Sites 배포는 역사 기록이다.

소스는 `viewer_A05/current_set_content.py`, `current_guide_steps.py`, `set_sources/manual_current.html`이다. 공개 표현은 `showcase_content.py`와 `showcase_analysis.py`, 공개 파일 허용목록은 `verify_showcase.py`가 관리한다. [빌드 안내](../viewer_A05/README.md)를 따른다.

현재 다운로드는 STL15종·전체STEP1종·Head A04 Gerber1종 및 공개 HTML 묶음이다. 내부 구매서·다른 제품 제조파일·과거 리비전·감사 원자료는 공개하지 않는다. 3D 주석은 형상 밖에 배치하고 전체 표시 on/off 설정을 공유한다.
