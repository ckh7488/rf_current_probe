## 우선하는 조립 방식

사용자는 작은 실리콘 패드 재단·적층과 별도 스프링 추가를 원하지 않는다. 권선이 보이는 열린 플라스틱 받침을 우선한다. 기존의 커터칼 재단 허용과 A07 패드안은 이 요구로 대체한다.

- 권선·권선 리드·Head PCB·SMA 앞은 열어 둔다. 권선을 피해 만든 공간을 다시 패드나 덮개로 채우지 않는다.
- 코어의 권선 없는 바깥 부분을 넓은 플라스틱 받침으로 받친다. 탈착식 고정바는 밖에서 보이고 분리할 수 있어야 한다.
- 코어를 치수에 딱 맞춰 압입하지 않는다. 코어 두께 편차를 고정바의 조립 높이로 받아들이는 방식을 먼저 검토한다.
- 별도 스프링, 수작업 재단 패드, 접착제로 틈 메우기, 사용자 드릴/줄 가공을 기본 조립에 요구하지 않는다.
- 반복 개폐 체결은 관통 홀과 교체 가능한 너트를 사용한다. 플라스틱 나사산 또는 얇은 스냅 턱의 반복 변형을 검증 없이 내구성 해법으로 취급하지 않는다.
- 권선 노출은 정비 공간의 해결이다. 코어 맞댐, 과조임에 의한 코어 파손, 조립 공차와 반복 측정까지 자동으로 해결된 것은 아니다.

## 이어서 확인할 구체 항목

1. 고정바를 조이는 힘이 권선·리드에 닿지 않는지, 코어를 점으로 누르지 않는지.
2. 서로 다른 코어 두께에서도 고정바가 먼저 하우징에 걸리거나 코어가 흔들리지 않는지.
3. 별도 스프링 없이 상하 코어가 맞닿는 닫힘 구조의 여유와 과조임 하중 경로.
4. 열린 상태에서 코어 이탈 방지와 나사/너트의 실제 접근·분리 순서.
5. 최종 재료·구성의 RF 영향과 개폐 반복성. 금속 이격 거리만으로 무영향을 선언하지 않는다.

## 현재 구현 상태
