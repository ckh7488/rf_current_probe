## 조립 순서

1. 바닥·아래 몸체·뚜껑을 선조립한다. PA66 연결 나사와 지정 와셔·너트를 쓰며 휘어진 출력물을 나사로 당겨 맞추지 않는다.
2. 아래 코어에 얇은 절연층과 연속5턴을 감는다. 맞댐면은 비우고 가동 코어에는 배선을 연결하지 않는다.
3. 맨 PCB에서 SMA5핀 무응력 삽입·평평한 안착을 확인한다. SMA만 선납땜하고 권선 끝은 자유 상태로 둔다. 지그 PCB의 SMA2개도 장착 전에 납땜한다.
4. H05 지정 경로의 역순으로 헤드 PCB를 넣는다. 탈착 방향은 먼저0.3 mm 띄우고45° 기울이며4 mm 이동하는 경로다. 장착면에 누른 채 비틀지 않는다.
5. PA66 M2×12 두 개로 고정한 뒤 권선을 S+/S−에 납땜하고 아래 고정바를 단다. 분해 전에는 권선을 탈납한다.
6. 상부 코어·개폐 손나사와 C09 프레임/기존 구동축을 조립한다. M4×70/M6×120 기성 축은 절단·압입하지 않는다. 축은 와셔/너트로 자유 회전할 여유를 조정한다.
7. 자연 착좌·양쪽 코어 맞댐·구경·나사물림·개폐/클램프 동작을 확인한 후 [최신 인수 순서](../reviews/fresh_system_audit_20260928/FIRST_ARTICLE.md)와 [T01~벤치 절차](G2_BENCH_PROCEDURE.md)를 따른다.

기존 [46단계 조립 설명](https://ckh7488.github.io/showcase/reports/rf-current-probe/assembly-guide.html)의 연결/순서는 유지되며 로컬46단계 동기화는 DEC-058에서 완료했다. 공개3D와 출력 다운로드는 A14/C07 설명일 수 있으므로 A16/C09 실제 파일 선택을 대신하지 않는다. 보강으로 바뀐4종은 위 인계표로 식별한다.

뒤쪽 M2 너트는 가는 평팁으로 잡는다. 외경6.5 mm 소켓은 홀더와 간섭한다. H04의 끝단0.6×1.5 mm·가는 구간25 mm 및 M3 외경8 mm 관형 공구 포락은 설계 검사 범위이며 실제 파지력은 첫 조립에서 확인한다. C09의 계산100 N 하중을 허용 체결 토크나 최대 수동 조작력으로 환산하지 않는다.

## 제조 상태와 재제작

[R2 재생성](../reviews/fresh_system_audit_20260928/reproduction.json)과 [A16 재생성](../reviews/fresh_a16_audit_20260928/reproduction_and_details.json)을 새로 실행했다. 원본 디렉터리에 과거 builder를 실행하지 말고 별도 폴더를 사용한다.

R2 PCB·조립 기하 검사와 별도로 C09 강도 재검토를 먼저 닫는다. 현재 전체 출력 제작 GO를 확정하지 않는다. 실제 업체 파일 교체·CAM/완성홀 확인·출력휨 조건·사용자 생산승인은 별도다. 이번 검수는 구매·업로드·결제·외부 발송을 수행하지 않았다. 일반 출력 공차가 기능면의 휨이나 실제 코어 접촉력·RF 정확도까지 보증하지 않는다.
