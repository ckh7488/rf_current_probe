측정 전에, 조립 상태와 저장 폴더부터

먼저 상대 응답을 확보합니다. 전류 모델과 기준면이 확인된 범위만 전류로 환산합니다.

  1. 조립 절차 A08의 무전원 점검 기록을 확인합니다. 실제 헤드·코어·턴 수·지그 리비전이 이 문서와 다르면 차이를 기록하고 해당 조립·시험 단계부터 재확인합니다.
  2. 측정 ID별 새 폴더를 만들고 헤드 ID, 지그 ID, 장비 HW/FW/GUI 버전, 케이블·어댑터·부하·교정키트 ID와 사진을 저장합니다. 이전 측정 파일은 덮어쓰지 않습니다.
  3. LibreVNA와 테스트 케이블 2개, 맞는 성별의 SOLT 표준, 대역·전력 정격이 확인된 외장 50 Ω 부하 1개를 준비합니다. 커넥터 모델·외형·어댑터를 확인하고 케이블을 별도로 지지합니다.
  4. RF OFF 상태에서 시작합니다. 아래 순서에 따라 케이블을 연결하고 수신기/부하가 올바른지 확인한 뒤 RF를 켭니다.
