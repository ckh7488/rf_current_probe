# RF Current Probe — 결정 기록

**9/28 최종 추가 판정 — C09 강도 재검토:** 좌우 가이드 각각50 N 벌림 하중의2 mm 메시에서 최대 인장응력29.901 MPa로 기존27.5 MPa 기준을 초과했다(전형55 MPa 대비1.84배). 초기3 mm 결과의 전체 강도 GO를 유지하지 않는다. PCB·조립 기하 통과와 구분하며, C09 보강 또는 근거 있는 형상/하중 재검토 후 같은 기준으로 재판정한다. 실물 파손 확정은 아니다. [최종 검수](../reviews/fresh_system_audit_20260928/REPORT.md), [메시 비교](../reviews/fresh_system_audit_20260928/MESH_REFINEMENT.md). 아래 날짜별 GO 문구는 앞선 검토 이력이다.

기준 문서: [RF_CURRENT_PROBE_WHITEPAPER.md](RF_CURRENT_PROBE_WHITEPAPER.md).

각 결정에는 날짜, 변경 항목, 이전 결정/상태, 새 결정, 근거, 영향받는 요구사항, 재시험 항목을 남긴다. 요구사항 추적 ID는 [REQUIREMENTS.csv](REQUIREMENTS.csv)를 따른다.

## DEC-008 — 교정지그 제조사 자료의 부호 검산

| 항목 | 기록 |
|---|---|
| 날짜 | 2026-09-15 |
| 변경 항목 | 백서 11.5절의 외부 자료 의심 식 확인 |

| 새 결정 | 공식 원문을 확인하고 이상적 정합 50 Ω 조건에서 `S21[dB]=Pout−Pin`, `ZT[dBΩ]=Pout−Pin+20log10(50)`을 유지 |
| 근거 | [Tekbox TBCPx_CAL Manual V1.0](https://www.tekbox.com/product/TBCPx_Calibrators_Manual.pdf) 1~2쪽, 조회일 2026-09-15. 2쪽의 `Pin−Pprobe+34`와 `S21+34`는 표준 S21 정의에서 서로 일치하지 않음 |
| 영향받는 요구사항 | CAL-02, CAL-03, CAL-05, SW-02 |
| 재시험 항목 | G2의 주파수·기준면·단위·부호 자동시험과 G4의 실제 지그 전류 모델 검증 |
| 확인 결과 | CALCULATED: Python 3.12.6 산술 검산에서 Pin=0 dBm / Pout=−20 dBm / 정합 50 Ω일 때 I=4.472136 mA RMS, Vout=22.360680 mV RMS, ZT=5 Ω=13.979400 dBΩ. 합성 S-parameter 자동시험·실측 교정은 미실행 |

이 예제는 코어 위치의 전류가 알려지는 이상적 정합 모델이다. 실제 지그에서는 반사·손실·기준면·분기 전류와 헤드 부하를 검증한 뒤 적용한다. S11이 좋다는 이유만으로 절대 전류 모델을 확정하지 않는다. 원문 재확인 및 산술 검산은 G1 전체 완료나 CAL-05의 자동시험 통과를 의미하지 않는다.

독립형 가능성에 관한 후속 질문은 설계 변경 승인으로 해석하지 않았다. 현재 수동 헤드·오실로스코프 연결 범위를 유지한다.
