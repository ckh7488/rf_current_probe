# 다음 컴퓨터에서 이어갈 실행 지침

## 1. 우선순위와 인계 완료 조건

목표는 직각 SMA로 조립한 A03에서 5턴 헤드의 **1–150MHz** 실제 반사·전달·반복성을 확보하고 유효한 구간만 조건부 ZT로 표시하는 것이다. 전체1–500MHz 특성화는 이후 확장이다. 이번 ZIP의 검증은 이관/소프트웨어 검증이며 실물 통과가 아니다.

현재3MΩ, 클램프 HOLD, 장비/키트 미식별을 먼저 처리한다. 5턴을 바로3턴으로 바꾸거나 구매 선정·G0–G3를 다시 시작하지 않는다. 필요한 것만 실제 물어보고, 이미 확보한 원본·자료·계산을 스스로 읽는다. 처음부터 긴 질문 목록을 주지 않는다.

진행 시 각 단계의 images 그림을 보여주고 “목적 → 연결할 두 단자 → 실제 설정 → 저장 파일 → 확인할 값” 순서로 한 단계만 안내한다. 사진/측정 숫자는 물리 관측이므로 사용자가 수행해야 한다. 연결이 바뀌면 사진과 setup ID를 남기고 RF OFF를 먼저 확인한다. 코드나 설치 오류가 나면 로그를 보존하고 수정/재시도한다. 해결하지 않은 하드웨어 문제를 계산 성공으로 덮지 않는다.

## 3. 3MΩ 접속 문제를 먼저 분리

R00 그림을 따른다. 탐침끼리 단락한 기준, S+↔S− 실제 납땜 금속, 헤드 SMA 중심↔외피를 각각 Ω 숫자와 단위로 기록한다. 에나멜 표면을 찍으면 코팅 때문에 높은 저항이 나올 수 있다. 납땜 두 점에서도3MΩ면 구리 권선의 정상 도통이 아니다. 인두3초는 피복 제거 보증이 아니다.

리드 끝만 충분히 벗겨 구리가 둘레 전체에 보이는지 확인하고 예비 납땜한다. 선 중간 권선 피복이나 코어 접합면을 훼손하지 않는다. PCB를 오래 가열해 패드를 들뜨게 하지 않는다. 두 납땜부/선 끝 사이를 구간별로 측정하면 접촉 불량 위치를 좁힐 수 있다. 손이 탐침을 함께 잡지 않게 한다.

헤드의 정상 권선은 SMA 중심↔외피가 DC 저저항이다. 반대로 **외장 부하를 뺀 빈 지그의 중심↔외피는 DC 쇼트면 안 된다**. 빈 헤드 PCB에 권선이 없을 때도 중심↔외피는 개방이어야 한다. 도통 부저만으로 납땜 브리지/권선 단락턴을 구별할 수 없으므로 육안/배선 확인도 필요하다.

## 4. 클램프 HOLD에서 가능한 측정

project/reviews/clamp_fit_failure_20261026/REPORT.md의 사용자 사진과 공칭 CAD 간격을 읽는다. 실측 유격 수치로 재표기하지 않는다. C04B 큰축과 F12 주변을 더 강하게 조이는 것으로 해결했다고 선언하지 않는다. 이번 작업은 기계 재설계나 출력 발주를 승인한 것이 아니다.

헤드·지그를 움직이지 않게 **코어 밖에서 비도전성 임시 벤치 지지**할 수 있으면 정적 상대 측정은 진행할 수 있다. 가능 여부/실제 사진/위치 안정성을 확인한다. 귀환·금속 지지대·나사·동축이 코어 구멍을 통과하거나 단락턴을 만들면 안 된다. 안정된 지지를 만들 수 없으면 빈 지그/부하/장비 측정은 계속하고 헤드 반복성·절대 교정은 미완료로 남긴다. 구조를 잘라내거나 구멍을 새로 뚫지 않는다.

## 5. 기준면과 파일 수집

R01–R07 및 MEASUREMENT_PLAN.json을 따른다. 주파수 그리드는 이번 제안1–150MHz linear1601점을 실제 장비 지원/교정과 맞춰 채택하며, 좁은 null 주변은 별도 정밀 sweep을 저장한다. R02는 공진 진단용1–600MHz 별도 교정이다. 양 범위의 교정 ID를 분리한다. source-level 변경/새 어댑터/케이블 변경은 유효성을 다시 확인한다.

교정파일·kit모델·setup에 외부 파일 경로가 있으면 관련 원본까지 세션 calibration에 수집한다. 확장자만 바꾸어 S2P를 만들지 않는다. 네 S-parameter가 동시에 갱신된 full2-port Touchstone을 저장한다. 파일 R50과 단위/범위를 검사한다. S21=출력P2/입력P1, S12=반대방향이며 단순히 이름을 바꾸지 않는다.

역방향은 지그IN/OUT을 실제 교환하고 장착 through와 전달을 다시 얻는다. 헤드 권선 방향/코어 전류 반전의 부호를 사진으로 남긴다. 새 load ΓL 측정의 별도 암 기준면이 필요하며, 보유 kit가 맞지 않으면 현재로서는 UNKNOWN이다. ΓL=0이나 K=1을 채워 절대값을 강제로 만들지 않는다. 이 상태에서도 상대 S21·빈 지그·레벨/재장착 시험은 유용하다.

## 6. 대조 실험과 품질 해석

기본 소스 OFF 대조는 R05 결선·IFBW·평균·위치를 유지하고 소스만 끈 수신 잡음이다. 별도 파일 noise_source_off와 화면을 저장한다. RF OFF 상태에서 헤드를 지그 밖으로 옮긴 뒤 출력 케이블과 주변 배치를 최대한 유지한 직접 픽업 대조를 저장한다. 이 방법으로 물리 배치/상호작용도 달라지므로 순수 누설의 완전 분리라고 단정하지 않는다. 사진과 원자료, 변화한 일차 through를 함께 비교한다.

상쇄 대조는 안전한 수동 시험 배선에서 같은 일차 전류의 정방향·귀환 도체를 둘 다 코어에 통과시켜 합전류가 상쇄되도록 해야 한다. **기존 A03의 귀환을 임의로 잘라 재배선하지 않는다.** 보유 부품으로 그 배선을 만들 수 있는지 별도 검토하고 등가 구동 전류/기준 측정·위치를 확보한 뒤 시험한다. 불가능하면 cancellation UNASSESSED로 남긴다. 정규화하지 않은 S21 차이만20dB라고 합격시키지 않는다.

재장착5회는 파일이5개 있다는 사실과 다르다. 코어를 완전히 열고 닫는 각 회차의 위치·부하·전류 기준·변경 내역이 필요하다. 백서14.5의 **점별 흩어짐 ±1dB**를 적용할 때 선택한 기준(평균/기준회)과 모든 회차의 점별 편차를 공개하고 peak-to-peak와 혼동하지 않는다. 전체 대역 한 숫자 평균으로 실패 구간을 지우지 않는다.

선형성은 source+10dB에 원시 수신 전압 레벨+10±1dB 목표다. 정규화S21 자체는 거의 유지되어야 한다. VNA 명목dBm은 코어 전류의 표준값이 아니다. SNR10dB는 초기 검출 판단용일 뿐 ±2dB 정확도 보증이 아니다.

## 7. 분석 실행과 K의 한계

tools/Setup-Analysis.ps1은 새 project/.venv-rf에 동봉된 Windows x64 CPython3.12 wheels를 오프라인 설치한다. Python 자체는 동봉하지 않았다. Python3.12 x64를 공식 python.org에서 설치한 뒤 실행한다. 다른 OS/Python은 별도 venv에서 project/analysis/requirements.txt를 설치하고 관련 시험을 수행한다. 기존 .venv 런처는 보존용이다. 설치가 실패하면 로그/ABI/버전을 확인하고 지원되는 환경을 준비한다. 핀을 몰래 변경하거나 시험을 통과했다고 쓰지 않는다.

프로젝트 루트(project/)에서 실행한다. <session>과 결과 폴더는 실제 생성된 이름으로 바꾼다. 출력 폴더는 새 이름이어야 한다.

```powershell
.\.venv-rf\Scripts\python.exe -m analysis.rfcp measurements/raw/<session>/probe_transfer_5t_Lm30.s2p --metadata measurements/raw/<session>/probe_transfer_5t_Lm30.json --out measurements/processed/<session>_relative
```

양식에 관측값/ID/단위/clipped를 채워야 한다. 초기 mode=relative, phase_validated=false, uncertainty_db=null, valid_frequency_bands_hz=[]를 유지한다. 실측 수집 전 템플릿을 실행하면 거부되는 것이 정상이다. `analysis/OUTPUT_REFERENCE.md`와 bundle_template을 보고 출력 기준 모드로 전환한다. forward/reverse K CSV, review CSV, 원본 해시, 실제 각 기준면/부하 교환/검토 근거가 필요하다.

수정된 SMA 근사 모델은 **빈 지그**의 drawing-based PEC/무손실 계산이다. K는Icore/Iout. 실제 헤드 장착/부하/재료 오차/위상 적용성 평가를 거쳐야 하며 두 포트 S자료만으로 내부 코어 전류가 자동 확정되지 않는다. 실물 독립 전류 기준이 없으면 관련 모델 오차 예산을 평가하고 유효성 범위를 제한한다. 정/역방향 일치로 공통 모델 오차를 지울 수 없다.

기존 fullwave 실패의0면적 전류 루프는 수정됐다. 새모델 150MHz에서 직각−수직 ΔS21약−0.0029dB/−4.14°, ΔK약−0.0106dB/+2.01°다. 이는 작은 예상 차이를 지지하는 근사 계산이며 실물 최대오차 보증이 아니다. 전역에너지−60dB나 전체PCB 격자수렴을 달성한 것으로 쓰지 않는다. 최신 REPORT/VALIDATION과 raw/모델/source를 읽는다.

## 8. 스코프와 종료 인계

R09와 project/docs/END_TO_END_REHEARSAL.md 3–5절을 따른다. P1→R06→CH1에 낮은 CW를 직접 넣어 receiver gain(표시 기본파V/검증된 기준V)을 주파수/설정별로 확인한다. 별도 P1→CAB-P1→P2로 같은 CW 설정의 기준 레벨을 기록한다. LibreVNA 레벨/고조파/스코프 부하 차이의 불확도를 남긴다. R05를 쓰면 VNA로 그 감쇠기 응답을 따로 얻고 중복 보정하지 않는다. 전체RMS/FFT피크를 기본파 RMS로 넣지 않는다.

원 MSO4054라면 DC/내부50Ω/FULL, 대역 조건5mV/div–1V/div500MHz·2–4.98mV/div350MHz·1–1.99mV/div200MHz, 주변≤30°C·초과1%/°C감소를 확인한다. 50Ω최대5Vrms 및 피크±20V/DF≤6.25%는 문서 조건이며 운용 목표나 프로브 보호 정격이 아니다. 실제 다른 모델이면 그 공식 매뉴얼로 갱신한다. 보호접지 제거/쉴드 임의절단/고전압직접적용 금지.

종료 보고에는 실제 확보 파일·설정·기준면·유효주파수·실패 구간·미검증 이유·다음 물리 측정을 남긴다. 보고서의 데이터 종류를 명시한다. 절대ZT가 없으면 상대노이즈 비교 도구로만 보고하고 한계를 표시한다. 현장 전 DC합전류에 의한 감도 변화·보호·삽입/링크 영향은 별도 검증한다.
